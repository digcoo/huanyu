# 级联交叉突破（cascade）

> 状态：**已实现**  
> API：`strategy=cascade`  
> 展示名：**级联交叉突破**（Tab 简称：**级联交叉**）

---

## 1. 产品定义

```
命中 = [可选] 双低支撑门 ∧ 无阻力 MACD 门 ∧ MACD 交叉 low 门
     + [可选] 近 6 日日均成交额 ≥ 门槛（默认 3000 万）
     + 启用档位内任一档满足级联突破（多档勾选取**并集**）
     + [可选] 须 min30 跨日桶柱内突破（ul* 沿用超短 Tab）
```

### 1.1 可选三门

| 参数 | 默认 | 说明 |
|------|------|------|
| `caEnableDualLowGate` | 关 | 双低支撑门 |
| `caEnableMacdGate` | 关 | 无阻力 MACD 门 |
| `caEnableCrossLowGate` | 关 | MACD 交叉 low 门 |

三门均关闭时不做门控。

### 1.2 基准 K

日 / 周 / 月各自 lookback 内**最近一根 MACD 金叉或死叉 K**（**非当前 K**）为基准 K，取 **high** 为突破线。

### 1.3 级联突破（日 K 边沿 + 上级确认）

**统一用日 K 判定「今日刚突破」：**

- 今日日 K：`close > 基准 K.high`
- 昨日日 K：`close ≤ 基准 K.high`

| 启用档位 | 日 K 突破对象 | 级联确认（上级须已站上其基准 high） | 附加约束 |
|----------|---------------|-------------------------------------|----------|
| 日基准（默认开） | 日基准 K.high | 周 K close > 周基准 K.high | — |
| 周基准 | 周基准 K.high | 月 K close > 月基准 K.high | **日 close > 日基准 K.high** |
| 月基准 | 月基准 K.high | （年 K 暂不要求） | **日 close > 日基准 K.high** |

周/月档额外要求日收盘已站上日基准 high，用于过滤仅在大周期反弹、日级仍受压的标的。

多档同时勾选时，各档独立判定，**任一档命中即入池**（并集）；每档信号分别标明 `signalTier=day|week|month`。

### 1.4 其他参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `caEnableDay/Week/Month` | 日开 / 周关 / 月关 | 启用档位 |
| `caLookbackDay/Week/Month` | 60 / 52 / 36 | 各周期交叉 K 回溯 |
| `caMinAmountWan` | **3000** | 近 6 日日均成交额（万）；**0=不启用** |
| `caRequireUltra` | 关 | min30 跨日桶柱内突破 |

## 2. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=cascade&all=1&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=cascade&...` | 写库 |
| `GET /stock/{code}/cascade/markers?period=day\|week\|month` | K 线标记 |

---

## 3. 消息格式

- **趋势**：`[CASCADE]级联交叉突破|可选三门|月K基准级联突破`（示例）
- **信号**：`级联交叉突破,crossType=GC,signalTier=day,refPeriod=day,refDay=...,refHigh=...,sigDay=...,sigClose=...,prevDay=...,prevClose=...`
