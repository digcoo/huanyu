
# 凹凸波段突破（waveperiodgate）



> 状态：**已实现**  

> API：`strategy=waveperiodgate` + `wpgTier=day|week|month`  

> 小程序展示名：**凹凸波段突破**（短线日档 / 中线周档 / 长线月档）



---



## 1. 产品定义



三档独立评估，每次请求只评一个档位（由 `wpgTier` 指定）。



**命中须同时满足：**



1. **本档凹/凸边沿突破**（按末波段形态择一）

2. **本档 MACD 柱 > 0**

3. **周/月凹凸形态门**（周、月须同时满足）

4. **周/月收盘价 > 末波段底**（周、月须同时满足）

5. **年/周/月全部收阳**（三周期须同时满足）



| 档位 | 评估周期 |

|------|----------|

| **短线（日）** | 日 K |

| **中线（周）** | 周 K |

| **长线（月）** | 月 K |



lookback 窗口内须至少 **2 个完整阳波段**。



### 1.1 凹/凸边沿突破



**突破**统一定义：在当前档位 K 序列中，**前一根 K 收盘 ≤ 突破线**，且**信号 K 收盘 > 突破线**。



| 末波段形态 | 突破线 | 边沿条件 |

|------------|--------|----------|

| **凹** | 末波段 high | 前 K close ≤ 末波段 high **且** 信号 K close > 末波段 high |

| **凸** | 前 K high | 前 K close ≤ 前 K high **且** 信号 K close > 前 K high；**且** 前 K close 不得 > 再前 K high（首次突破） |



**前 K** = 信号 K 的紧邻上一根（`size - 2`）。



### 1.2 本档 MACD > 0



信号档（日/周/月）最后一根 K 对应的 **MACD 柱值 > 0**（与金叉策略 `UnilateralMacdTools` 同义）。



### 1.3 周/月凹凸形态门（三档共用）



短线、中线、长线均须**同时**满足周、月末两波段形态门：



| 末波段形态 | 周 / 月条件 |

|------------|-------------|

| **凹波段** | 收阳，且当前价（收盘价）> 末波段 high |

| **凸波段** | 收阳，且当前价（收盘价）> 同档前 K high |



### 1.4 周/月收盘价 > 末波段底（三档共用）



| 周期 | 条件 |

|------|------|

| **周 K** | 周收盘价 > 周末完整波段的波段底（首阳 low） |

| **月 K** | 月收盘价 > 月末完整波段的波段底（首阳 low） |



### 1.5 年/周/月全部收阳（三档共用）

年、周、月最后一根 K 须**全部**收阳（`close > open`）。

### 1.6 可选配置



| 参数 | 默认 | 说明 |

|------|------|------|

| `wpgEnableConcaveBreakout` | **true** | 凹波段边沿突破 |

| `wpgEnableConvexBreakout` | **true** | 凸波段边沿突破 |

| `wpgEnableTierMacdPositive` | **true** | 本档 MACD 柱 > 0 |

| `wpgEnableWeekMonthBandShapeGate` | **true** | 周/月凹凸形态门 |

| `wpgEnableWeekMonthBandLowGate` | **true** | 周/月收盘价 > 末波段底 |

| `wpgEnableYearWeekMonthYangGate` | **true** | 年/周/月须全部收阳 |

| 勾选凹+凸 | — | **并集**：按当前末波段形态（凸/凹）择一判定 |



### 1.7 波段与凸凹



```

末波段.bandHigh > 次波段.bandHigh → 凸，否则 → 凹

```



### 1.8 Lookback 默认



| 参数 | 默认 |

|------|------|

| `wpgLookbackDay` | 120 |

| `wpgLookbackWeek` | 52 |

| `wpgLookbackMonth` | 36 |

## 3. 实现索引



| 模块 | 类 |

|------|-----|

| 策略 | `WavePeriodGateStrategy` |

| 评估 | `WavePeriodGateEvaluator` |

| MACD 门 | `WavePeriodGateTools.passesTierMacdPositiveGate` |

| 周月末波段底 | `WavePeriodGateBandLowGateTools` → `WeekMonthBandLowGateTools` |

| 年周月收阳 | `WavePeriodGateYearWeekMonthYangGateTools` → `YearWeekMonthYangGateTools` |

| 参数 | `WavePeriodGateStrategyParams` / `wpg*` |
