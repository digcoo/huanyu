
# MACD金叉波段High突破（macdgcwh）

> 状态：**已实现**  
> API：`strategy=macdgcwh` + `mgcwhTier=day|week|month`  
> 展示名：**MACD金叉波段High突破**（短线日档 / 中线周档 / 长线月档）

---

## 1. 产品定义

三档独立评估，每次请求只评一个档位（由 `mgcwhTier` 指定）。

### 1.1 必选条件

1. **最近一根 MACD 交叉 K**（不含信号 K）须为**金叉**；若为死叉则不命中。
2. **信号 K 本身不得为 MACD 金叉**；若末 K 为金叉则跳过。
3. 以该金叉 K 定**基准波段**：
   - 金叉 K 为**阳 K**：取该 K 所属的**完整**阳波段（未完结则无基准波段，不命中）。
   - 金叉 K 为**阴 K**：取该 K 之前的最后一个完整阳波段。
4. **同档边沿突破**基准波段的 **bandHigh**：
   - 前 K `close ≤ bandHigh`
   - 信号 K `close > bandHigh`

边沿突破与凹波段突破同义（`WavePeriodGateTools.passesConcaveBreakout`）。

### 1.2 可选配置

| 参数 | 默认 | 说明 |
|------|------|------|
| `mgcwhEnableMinAmountFilter` | **true** | 启用近 6 日日均成交额门 |
| `mgcwhMinAmountWan` | 3000 | 最低日均成交额（万） |
| `mgcwhEnableSignalRiseGate` | **true** | 启用末 K 上涨率门 |
| `mgcwhSignalRisePct` | 3 | 末 K 上涨率阈值（%，如 3 表示 >3%） |

### 1.3 金叉 K 回溯（lookback）

| 档位 | 默认 lookback |
|------|---------------|
| 日档 | `mgcwhLookbackDay` = 60 |
| 周档 | `mgcwhLookbackWeek` = 52 |
| 月档 | `mgcwhLookbackMonth` = 36 |

### 1.4 档位

| 档位 | `mgcwhTier` | 评估周期 |
|------|-------------|----------|
| 短线 | `day` | 日 K |
| 中线 | `week` | 周 K |
| 长线 | `month` | 月 K |

---

## 2. API 示例

```
GET /stock/findMy?strategy=macdgcwh&mgcwhTier=week&all=1&page=1&size=12
```

关闭可选门、仅保留核心逻辑：

```
GET /stock/findMy?strategy=macdgcwh&mgcwhTier=day&mgcwhEnableMinAmountFilter=0&mgcwhEnableSignalRiseGate=0
```

---

## 3. 与 macdgc / macdcrosstier 的区别

| | **macdgcwh** | **macdgc** | **macdcrosstier** |
|--|--------------|------------|-------------------|
| 信号 K 为金叉 | **排除** | **要求** | 路径之一 |
| 最近交叉 | 须金叉 | 不要求 | 金叉/死叉均可 |
| 突破线 | **基准波段 High** | 无 | 交叉 K high |
| 破前 K 高 | 无 | 无 | 有 |
