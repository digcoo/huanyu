# 长线策略（long · v1）

> 状态：**已实现**  
> API：`strategy=long`  
> 展示名：**长线策略**

---

## 1. 产品定义

**一句话**：前 N 个自然年（默认 2）月 K 作基准，本年月 K 突破前 K 高且站在基准 Low 之上即可入选（与中线对称，周期由周K→月K、月桶→自然年桶）。

```
命中 = 前 N 自然年内月K 存在基准K（A1 年内局部新高强K；若无则 A2 最近强K）
     + 本年月K 存在突破K（强K，close > 前K.high，close > ref.low，
       且 突破K.low 或 前K.close 至少其一 < ref.high）
     + 成交额 ≥ 门槛
     + 可选 MACD / 年金叉
     + **默认**：须同时满足超短 30m 突破（`lgRequireUltra`，共用 `ul*` 参数）
```

**不含大阴线过滤**。

---

## 2. 周期映射（梯子四档）

| 超短线 | 短线 | 中线 | **长线** |
|--------|------|------|----------|
| 30m K | 日 K | 周 K | **月 K** |
| 分组：交易日 | 自然周 | 自然月 | **自然年** |
| 背景：前 2 日 | 前 2 周 | 前 2 月 | 前 **2 年**（可调） |
| 信号桶：当日 30m | 本周日 K | 本月周 K | **本年月 K** |

---

## 3. 基准K（ref）

- **数据**：月 K
- **背景窗口**：信号自然年之前的 `lgPrevYears` 个完整年（默认 **2**，可调 1–4）
- **强K**：实体或涨幅 ≥ **5%**
- **A1**：每个自然年内，强 K 且 `high` 严格高于该年此前所有月 K 最高价；跨年取**最后一根**
- **A2**：A1 无结果时，向前取最近一根强 K

---

## 4. 突破K（signal）

- **信号桶**：**本年**（当前自然年）已走完的月 K
- **命中规则**：
  - **默认**：本年任意月 K 满足（多根取**最后一根**）
  - **`lgRequireCurrentBreakout=1`**：仅**最新一根**月 K 满足

---

## 5. 过滤与可选参数

### 硬过滤

| 参数 | 默认 | 说明 |
|------|------|------|
| 最低成交额 | 5000 万 | 近 6 日日均 |

### 可选（默认关）

| 参数 | 说明 |
|------|------|
| `lgRequireYearMacd` | 年 MACD > 0 |
| `lgRequireMonthMacd` | 月 MACD > 0 |
| `lgRequireYearGoldenCross` | 年 K MACD 金叉 |
| `lgRequireCurrentBreakout` | 当前月 K 须为突破 K |
| `lgPrevYears` | 基准背景年数（1–4，默认 2） |
| `lgRequireUltra` | 须超短 30m 突破（默认开，共用 `ul*`） |

API 字段前缀：`lg*`。
