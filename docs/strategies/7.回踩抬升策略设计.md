## 0. 命名（已定）

| 项 | 定稿 |
|----|------|
| **中文名** | **回踩抬升** |
| **英文/代码** | `retest` |
| **一句话** | 强反弹 → 回调企稳 → 再次上升时的介入结构 |

**取名理由**

- **回踩**：对应第二段「回调、二次回踩」，与主观描述一致。  
- **抬升**：承接仓库既有语言「底上移 / Low 上移」（`KlineCommonTools.checkLastLowShangYi`、`SignalTools` 梯子信号），强调 L1 抬高、结构不再创新低。  
- 与 **梯子突破** 区分：梯子突破抓「背景强 K 局部新高 + 信号桶内第一根突破」；回踩抬升抓「完整三段 swing：弹 → 踩 → 再起」。  
- 与 **深跌反弹** 区分：深跌反弹是 MACD 多周期拐点 + 单根突破，不要求 L0-H1-L1 结构。

## 1. 产品定义

### 1.1 统一叙事（一个引擎、两种宏观背景）

两种业务场景共用同一套 **三段锚点** 逻辑，仅 **宏观 Gate** 不同：

| 模式 | 代号 | 场景 | 用户语义 |
|------|------|------|----------|
| **下跌反转** | `bear` | 下跌趋势中，出现一段极好反弹，回调企稳后再升 | 深跌里找「第二脚」 |
| **上涨中继** | `bull` | 上涨趋势中，回调反弹后再次回踩企稳再升 | 趋势里找「旗形/二次回踩」 |

```
命中 = Gate
     + MacroGate(bear | bull)     // 可同时满足
     + 存在合格三段 (L0, H1, L1)
     + 强反弹段 (L0→H1)
     + 合格回调 (H1→L1)
     + 企稳再升 (signal)
     + 现价过滤
```

小程序文案：**强弹 · 回踩企稳 · 再次抬升**

### 1.2 与现有策略关系

| 策略 | 关系 |
|------|------|
| 梯子突破 `ladder` | **互补**：无 mandatory 回踩结构；可同时命中，列表用 score/标签区分 |
| 深跌反弹 `default` | **部分重叠**：bear 模式与深跌反弹同属偏空背景；回踩抬升更强调 swing 结构 |
| 老代码「突破梯子 High(区间 Low 上移)」 | bull 模式 **精神相近**，本策略将其产品化、可标记、可配参 |

## 2. 三段锚点（核心量化）

在 **操作周期** 的 lookback 窗口内识别四个点（类似 ladder 的 ref / signal，但语义不同）：

| 锚点 | 角色 | 含义 |
|------|------|------|
| **L0** | 起点低 | 强反弹前的 swing low |
| **H1** | 第一腿高 | L0 之后、回调前的 swing high（「极好的反弹」顶点） |
| **L1** | 回踩低 | H1 之后的 swing low（「回调企稳」低点） |
| **signal** | 介入 K | L1 之后**第一根**有效突破「回调段上沿」的 K 线 |

结构示意：

```
价格
  │        H1 ─── 强反弹顶
  │       ╱  ╲
  │      ╱    ╲  回调
  │   L0       L1 ─── 企稳低点（L1 ≥ L0 · 抬升）
  │              ╲
  │               signal ─── 再次上升（介入）
  └────────────────────────── 时间
```

### 2.1 Swing 点识别（默认）

- **分形法**：左右各 `fractalBars=2` 根确认局部高/低（实现简单，与 K 线缓存兼容）。  
- **备选**：ZigZag(阈值 = `ATR(14) × k`)，Phase 2 可选。

扫描顺序（在窗口 `[t-W, t]` 内）：

1. 找 L0 = 窗口内符合条件的最后一个「显著低点候选」（bear 模式需靠近阶段 low）。  
2. 在 L0 之后找 H1 = 第一个 swing high。  
3. 在 H1 之后找 L1 = 第一个 swing low。  
4. 在 L1 之后找 signal = 第一根满足 §3.4 的 K。

### 2.2 四档周期（首版全做，对齐 ladder）

| 档位 | 代号 | 操作周期 | lookback（默认） | 宏观定背景 |
|------|------|----------|------------------|------------|
| **超短** | S | 30m | 40 根 (~5 日) | 日 K |
| **短** | A | 日 K | 40 根 | 周 K |
| **中** | B | 周 K | 26 根 (~半年) | 月 K |
| **长** | C | 月 K | 24 根 (~2 年) | 年 K |

参数开关：`tEnableUltra/Short/Medium/Long`（与 ladder 命名习惯一致）。  
展示周期档位取命中中最高优先级 **S > A > B > C**，并受 `tTierMin` 过滤。

## 3. 各段判定规则（建议默认值）

### 3.1 强反弹段 L0 → H1（「极好的走势」）

| 条件 | 默认 | 参数名 |
|------|------|--------|
| 涨幅 | `(H1-L0)/L0 ≥ 8%`（各周期阈值对齐 `PeriodTypeEnum`） | `impulseMinGainPct` |
| 时长 | `3 ≤ bars ≤ 12` | `impulseMinBars` / `impulseMaxBars` |
| 强 K 根数 | ≥ 2 根 `isStrongBar` | `impulseMinStrongBars` |
| 强 K 阈值 | 30m/日 2%、周 2.5%、月 4.5% | 同 ladder |
| 量能（可选） | 段内均量 ≥ 前 10 根均量 × 1.2 | `impulseVolRatio`（默认关） |

### 3.2 回调段 H1 → L1（「回调」）

| 条件 | 默认 | 参数名 |
|------|------|--------|
| 回撤比 | `(H1-L1)/(H1-L0) ∈ [0.35, 0.65]` | `pullbackMinRatio` / `pullbackMaxRatio` |
| 时长 | `bars(H1→L1) ≤ bars(L0→H1) × 1.5` | `pullbackMaxBarsFactor` |
| **抬升** | **`L1 ≥ L0`**（允许等于，容忍 0.5% 噪声） | `allowEqualLow` |

### 3.3 企稳（L1 后、signal 前）

至少满足 **其一**：

| 规则 | 说明 |
|------|------|
| A. 低点不再创新低 | L1 后 `stabilizeBars=3` 根内，low 不低于 `L1 × (1-ε)` |
| B. 收回短均线 | close 站上 MA5 且 MA5 斜率 ≥ 0 |
| C. 小级别阳线 | L1 后至少 1 根强 K 收阳 |

首版：**A + signal 突破** 组合。

### 3.4 介入 K signal（「再次上升」）— 已定

**突破位 `pullbackHigh`（优先级）：**

1. **首选**：回调段内、L1 之前的 **局部 swing high**（`pullbackLocalHigh`）。  
2. **回退**：若局部 high 不存在或无法识别 → `H1 - pullbackMinRatio × (H1 - L0)`（H1 回撤线，与 `pullbackMinRatio` 默认 0.35 一致）。

**signal 条件**（第一根同时满足，语义对齐 `PreGoldenBreakoutTools`）：

- `high > pullbackHigh`  
- `close > max(prev.open, prev.close)`  
- **强 K**（默认开）  
- **现价过滤**：`stock.close ≤ signal.high`

## 4. 宏观 Gate（bear / bull）

参数面板：`tEnableBear`、`tEnableBull`（默认都开）。

### 4.1 展示规则（已定：分标签）

- bear / bull **独立判定**；同一标的、同一周期结构若两种 MacroGate 均满足，**同时展示两个标签**（如 `下跌反转` + `上涨中继`，或 `[bear][bull]`）。  
- **不做** bull 覆盖 bear 的优先级合并。  
- 列表卡片、详情页 trendMessage / tags 均保留双标签；score 可因双标签略加分。

### 4.2 下跌反转 `bear`

**MacroGate：至少 2 项**

| # | 条件 |
|---|------|
| 1 | 对应档宏观周期 MACD 柱 < 0（S→日、A→周、B→月、C→年） |
| 2 | close < MA60（日 K 口径），或阶段高点回撤 ≥ 25% |
| 3 | 背景 swing high 呈 lower high |

**结构附加**

- L0 距阶段 low ≤ 5%  
- H1 突破最近一个 lower high  

### 4.3 上涨中继 `bull`

**MacroGate：至少 2 项**

| # | 条件 |
|---|------|
| 1 | 对应档宏观周期 MACD 柱 > 0 |
| 2 | close > MA20 且 MA20 > MA60 |
| 3 | 背景 swing low 呈 higher low |

**结构附加**

- L1 不破 MA20（或前平台 low）  
- **二次回调严格校验**：Phase 2；首版用 bull Gate + `L1 ≥ L0` 即可

## 5. Gate（全策略通用）

与其他策略一致，`UnilateralGateTools`：

- 近 6 日平均成交额 ≥ 阈值（默认 3000 万，`tMinAmountWan`）  
- 周或月未跌破支撑 Low

## 6. 展示、评分、档位

### 6.1 周期档位 + 模式标签

| 维度 | 规则 |
|------|------|
| **周期档** | S/A/B/C，取命中中最高档（S > A > B > C），受 `tTierMin` 过滤 |
| **模式标签** | bear / bull **分开展示**，可同时出现 |
| **主图默认周期** | 与命中最高周期档一致（同 ladder `ladderPrimaryPeriod` 逻辑） |

### 6.2 Score（排序）

```
score = impulseScore(涨幅、强K数)
      + pullbackScore(回撤比越接近 0.5 越高)
      + macroScore(bear/bull 命中项数；双标签 +bonus)
      + (close 距 signal.high 越近越高)
```
