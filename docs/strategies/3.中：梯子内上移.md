# 中线策略（medium · v1 设计）

> 状态：**已实现**  
> API：`strategy=medium`  
> 展示名：**中线策略**

---

## 1. 产品定义

**一句话**：前 N 个自然月（默认 2）周 K 作基准，本月任一周 K 突破前 K 高且站在基准 Low 之上即可入选（与短线对称，周期由日K→周K、周桶→自然月桶）。

```
命中 = 前 N 自然月内周K 存在基准K（A1 月内局部新高强K；若无则 A2 最近强K）
     + 本月周K 存在突破K（强K，close > 前K.high，close > ref.low，
       且 突破K.low 或 前K.close 至少其一 < ref.high）
     + 成交额 ≥ 门槛
     + 可选 MACD / 月金叉
     + **默认**：须同时满足超短 30m 突破（`mdRequireUltra`，共用 `ul*` 参数）
```

**不含大阴线过滤**（不设前月/前年/前周实体阴线门槛）。

---

## 2. 周期映射（梯子三档）

| 超短线 | 短线 | **中线** | 长线 |
|--------|------|----------|------|
| 30m K | 日 K | **周 K** | 月 K |
| 分组：交易日 | 自然周 | **自然月** | 自然年 |
| 背景：前 2 日 | 前 2 周 | 前 **2 月** | 前 2 年 |
| 信号桶：当日 30m | 本周日 K | **本月周 K** | 本年月 K |

---

## 3. 基准K（ref）

- **数据**：周 K
- **背景窗口**：信号自然月之前的 `mdPrevMonths` 个完整月（默认 **2**，可调 1–4）
- **强K**：实体或涨幅 ≥ **5%**（默认 `mdMinStrongPct=0.05`）
- **A1**：每个自然月内，强 K 且 `high` 严格高于该月此前所有周 K 最高价；跨月取**最后一根**
- **A2**：A1 无结果时，自 signal 周前一根起**向前**，取最近一根强 K

---

## 4. 突破K（signal）

- **信号桶**：**本月**（当前自然月）已走完的周 K
- **单根条件**（同超短/短线，对象改为周 K）：
  1. 强 K
  2. `close > 前一根周 K 的 high`
  3. `close > ref.low`
  4. `signal.low < ref.high` **或** `prev.close < ref.high`
- **命中规则**：
  - **默认**：本月任意周 K 满足（多根取**最后一根**）
  - **`mdRequireCurrentBreakout=1`**：仅**最新一根**周 K 满足

---

## 5. 过滤与可选参数

### 硬过滤

| 参数 | 默认 | 说明 |
|------|------|------|
| 最低成交额 | 5000 万 | 近 6 日日均 |

### 可选（默认关）

| 参数 | 说明 |
|------|------|
| `mdRequireMonthMacd` | 月 MACD > 0 |
| `mdRequireYearMacd` | 年 MACD > 0 |
| `mdRequireMonthGoldenCross` | 月 K MACD 金叉 |
| `mdRequireCurrentBreakout` | 当前周 K 须为突破 K |
| `mdPrevMonths` | 基准背景月数（1–4，默认 2） |
| `mdRequireUltra` | 须超短 30m 突破（默认开，共用 `ul*`） |

API 字段前缀：`md*`（如 `mdMinAmountWan`、`mdPrevMonths`）。

---

## 6. 与旧 ladder「中档」的区别

- 旧 ladder 中档：首根突破、最强实体 ref 等 v1 规则
- 新 **medium**：与 ultra / trend 共用 **A1/A2 ref + 末根 signal + belowRefHigh**，独立枚举与参数
