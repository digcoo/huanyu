
# MACD金叉K突破（ultragc）

> 状态：**已实现**  
> API：`strategy=ultragc`  
> 展示名：**超短线 · MACD金叉K突破**（Min30）

---

## 1. 产品定义

超短线家族第二子策略，与 `ultra`（跨日桶柱内突破）并列；操作周期均为 **Min30**。

### 1.1 必选条件

1. **末 Min30 K**：最近一根 Min30 的 **MACD 柱 > 0**。
2. **基准 ref**：信号 K 之前、lookback 内最近一根 **MACD 金叉 K**（可来自前几日）。
3. **信号 K**：须落在**末交易日**的 Min30 序列内（首 / 中 / 末根均可）。
4. **边沿突破**：`prev.close ≤ ref.high` 且 `signal.close > ref.high`。
5. **涨幅门**：信号 Min30 相对前一根涨幅 > 阈值，默认 **1%**。

### 1.2 可选配置

| 参数 | 默认 | 说明 |
|------|------|------|
| `ulgcPrevDays` | 2 | 信号日前 N 个交易日（背景窗口） |
| `ulgcMaxBarsPerDay` | 8 | 每日最多纳入的 Min30 根数 |
| `ulgcGcLookbackBars` | 24 | 金叉回溯根数 |
| `ulgcSignalRisePct` | 1 | 信号 Min30 涨幅阈值（%） |
| `mgRequireDayMacd` | false | 日 MACD>0 可选门 |
| `mgRequireWeekMacd` | false | 周 MACD>0 可选门 |
| `mgRequireMonthMacd` | false | 月 MACD>0 可选门 |

## 2. API 示例

```
GET /stock/findMy?strategy=ultragc&all=1&page=1&size=12
GET /stock/findMy?strategy=ultragc&ulgcSignalRisePct=2&mgRequireDayMacd=1
```

---

## 3. 与 ultra 区别

| | **ultragc** | **ultra** |
|--|-------------|-----------|
| 基准 ref | 最近金叉 K 的 **high** | 跨日桶内强 K high |
| 末 K MACD | Min30 **> 0** | 无硬性要求 |
| 全局六门 | 不要求 | 成交额 + 可选 MACD 负门等 |
| 信号范围 | 末交易日任一根 Min30 | 末交易日任一根 Min30 |
