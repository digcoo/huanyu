
# MACD金叉（macdgc）

> 状态：**已实现**  
> API：`strategy=macdgc` + `mgcTier=day|week|month`  
> 展示名：**MACD金叉**（短线日档 / 中线周档 / 长线月档）

---

## 1. 产品定义

三档独立评估，每次请求只评一个档位（由 `mgcTier` 指定）。

### 1.1 必选条件

```
末 K 为 MACD 金叉（DIF 上穿 DEA，红柱）
```

### 1.2 可选配置

| 参数 | 默认 | 说明 |
|------|------|------|
| `mgcEnableMinAmountFilter` | **true** | 启用近 6 日日均成交额门 |
| `mgcMinAmountWan` | 3000 | 最低日均成交额（万） |
| `mgcEnableSignalRiseGate` | **true** | 启用末 K 上涨率门 |
| `mgcSignalRisePct` | 3 | 末 K 上涨率阈值（%，如 3 表示 >3%） |
| `mgcEnableHistoryRiseGate` | **true** | 启用近 N 根历史上涨率门 |
| `mgcHistoryLookbackBars` | 5 | 向前检视 K 根数（**不含**末 K） |
| `mgcHistoryRisePct` | 3 | 历史单根上涨率阈值（%） |

上涨率定义：`(close - 前收) / 前收`，严格大于阈值。

历史门：在末 K 之前的 `mgcHistoryLookbackBars` 根 K 中，**至少一根**上涨率达标即可。

成交额门：近 6 日日均成交额（不含当日 K），与既有策略一致。

### 1.3 档位

| 档位 | `mgcTier` | 评估周期 |
|------|-----------|----------|
| 短线 | `day` | 日 K |
| 中线 | `week` | 周 K |
| 长线 | `month` | 月 K |

---

## 2. API 示例

```
GET /stock/findMy?strategy=macdgc&mgcTier=week&all=1&page=1&size=12
```

关闭成交额门、仅保留金叉：

```
GET /stock/findMy?strategy=macdgc&mgcTier=day&mgcEnableMinAmountFilter=0&mgcEnableSignalRiseGate=0&mgcEnableHistoryRiseGate=0
```

---

## 3. 与 macdcrosstier 的区别

| | **macdgc** | **macdcrosstier** |
|--|------------|-------------------|
| 核心 | 末 K MACD 金叉 | 交叉 K 边沿突破 / 金叉上涨率 |
| 成交额 | 可选（默认开） | 无 |
| 破前 K 高 | 无 | 必选 |
| 波段门 | 无 | 有 |
