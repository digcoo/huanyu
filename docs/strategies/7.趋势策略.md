# 趋势策略（trendm）

> 状态：**已实现**  
> API：`strategy=trendm`  
> 展示名：**趋势策略**

---

## 1. 产品定义

```
命中 = 日 MACD 门 ∧ 周 MACD 门 ∧ 月 MACD 门   （同无阻力梯子，固定）
     ∧ 日 K 基准突破 ∧ 周 K 基准突破 ∧ 月 K 基准突破   （三周期同时）
     ∧ min30 超短梯子
```

### 1.1 无阻力 MACD 门

与 `nrf` / `bogo` 相同。

### 1.2 日/周/月基准突破（三周期须同时满足）

各周期独立、逻辑同 `bogo`：

1. 最近一根 MACD 金叉或死叉 K 为基准（**非当前 K**）
2. 前 K close ≤ 基准 high
3. 当前 K close > 基准 high

### 1.3 min30 梯子

- **强制**联检 30m 超短梯子（`UltraShortBreakoutTools`）
- 参数沿用小程序「超短」Tab 的 `ul*`

---

## 2. 与底部机会（bogo）区别

| 维度 | bogo | trendm |
|------|------|--------|
| 周期 | 日/周/月可选，**任一**命中 | 日/周/月 **同时**命中 |
| min30 | 无 | **强制** |
| 门控 | 无阻力三门 | 无阻力三门 |

---

## 3. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=trendm&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=trendm&...` | 写库 |
| `GET /stock/{code}/trendm/markers?period=day\|week\|month` | 基准/突破 K 标记 |

参数：`tmLookbackDay` / `tmLookbackWeek` / `tmLookbackMonth` + 合并 `ul*`。

---

## 4. 消息格式

- **趋势**：`[TRENDM]趋势|日周月无阻力MACD门|日周月基准突破|min30梯子`
- **信号**：日/周/月各一条，含 `refDay` / `sigDay` / `crossType=GC|DC`
- **min30**：超短策略信号（append 同 nrf）
