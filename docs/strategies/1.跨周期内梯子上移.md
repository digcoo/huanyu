# 跨周期内梯子上移（nrf · v3）

> 状态：**已实现**  
> API：`strategy=nrf`  
> 展示名：**跨周期内梯子上移**  
> 说明：原「柱子内上移（pillar）」已合并入本策略，不再单独提供 Tab / 扫描。

---

## 1. 产品定义

```
命中 = 双低支撑门 ∧ 无阻力 MACD 门 ∧ MACD 交叉 low 门   （固定三门）
     + 可选：近 6 日日均成交额 ≥ 门槛（默认 5000 万）
     + 当前档位：跨周期背景桶强 K 基准 + 柱内突破信号
     + 可选：须 min30 跨日桶柱内突破（ul* 参数，默认关）
```

### 1.1 档位（一次只跑一档）

| 档位 `nrfActiveTier` | 操作 K | 背景桶 | 信号 K |
|----------------------|--------|--------|--------|
| `short` | 日 K | 前 N 个**自然周**（默认 2） | **日 K** |
| `medium` | 周 K | 前 N 个**自然月** | **周 K** |
| `long` | 月 K | 前 N 个**自然年** | **月 K** |

### 1.2 基准 K（ref）

在背景桶内，**任一**满足下列条件的强 K 均可作基准（可能多根；展示取**离当前最近**的一根）：

1. **强 K**：大涨幅或大实体（同梯子 `BreakoutBarTools.isStrongBar`）
2. **柱内约束**：ref 与信号 K 之间（不含二者），每根 K 的 `close <= ref.high`

### 1.3 信号 K（突破 K）

在同一操作周期上，须同时满足：

1. `close > 前K.high`（须突破前一根 K 的高点；**不要求**突破 ref.high）
2. `close >= ref.low`
3. `min(当前K.low, 前K.close) <= ref.high`

默认 **`tr/md/lgRequireCurrentBreakout=1`（当前 K 须为突破 K）**；关闭则信号桶内任一根满足即可（多根取最后一根）。

## 2. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=nrf&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=nrf&...` | 写库扫描 |
| `GET /stock/{code}/nrf/markers?period=day\|week\|month` | K 线标记 |

### 参数

| 字段 | 说明 |
|------|------|
| `nrfActiveTier` | `short` / `medium` / `long` |
| `tr*` / `md*` / `lg*` | 背景周/月/年数、最低成交额、**当前 K 须为突破 K**（默认开）、须 min30 等；不含 MACD 可选开关 |

## 3. 消息格式

- **趋势**：`[NRF]跨周期内梯子上移|日K跨周桶|三门…|日K柱内上移`
- **信号**：`柱内突破K,period=day,refDay=...,refHigh=...,sigDay=...,sigClose=...`
