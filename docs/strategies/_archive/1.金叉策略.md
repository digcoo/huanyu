# 金叉策略（qsn · v4.0）

> 版本：v4.0 · 2026-06  
> 状态：**已实现**  
> 对应小程序 Tab：`trend`（金叉策略）  
> 对应后端枚举：`StrategyTypeEnum.TREND_NEW`（code = `qsn`）  
> 策略类：`DefaultTrendStrategy`

---

## 1. 产品定义

**一句话**：大周期 MACD 在零轴上方，小周期出现 MACD 金叉——按短/长两档捕捉不同节奏。

| 档位 | 大周期条件 | 金叉周期 |
|------|-----------|---------|
| **短线（S）** | 月 **或** 周 MACD > 0 | 日 MACD 金叉 |
| **长线（B）** | 年 **或** 月 MACD > 0 | 周 MACD 金叉 |

小程序文案：**短线 · 长线 MACD 金叉**

---

## 2. 总体判定

```
命中 = Gate 通过
     AND（短线 | 长线 任一启用且满足）
排序 = score（越高越靠前）
档位 = S（短线）/ B（长线）；两档同时命中时优先展示短线
```

---

## 3. Gate（硬门槛）

| # | 条件 |
|---|------|
| G1 | 在 `filterStockMap` 内 |
| G2 | 近 6 日平均成交额 > 5000 万（`uMinAmountWan`） |
| G3 | **月 MACD > 0** |
| G4 | 周或月未跌破近端支撑 Low |
| G5 | **前一周** K 非大阴线（阴线时实体跌幅 ≤ 5%） |
| G6 | **前一月** K 非大阴线（阴线时实体跌幅 ≤ 10%） |

---

## 4. 两档 MACD 条件

| 档位 | 大周期 MACD > 0 | 小周期 MACD 金叉 |
|------|----------------|-----------------|
| 短线 S | 月 **或** 周 | 日 |
| 长线 B | 年 **或** 月 | 周 |

金叉 = 红柱由负转正（`isIfRedGoldCross`）。

---

## 5. Score 与档位

| 项 | 分值 |
|----|------|
| 命中短线 | +40（月、周 MACD 均>0 另 +10） |
| 命中长线 | +35（年、月 MACD 均>0 另 +10） |
| 同时命中两档 | +15 |

## 7. API

- 列表：`GET /tts/stock/findMy?strategy=qsn&all=true`

可调参数：`uMinAmountWan`、`uEnableShort`、`uEnableLong`、`uTierMin`  
（`uEnableMedium` 已废弃，v4.0 起忽略）
