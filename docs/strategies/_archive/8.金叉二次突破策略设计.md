# 金叉二次突破策略设计（v2.0 · 已实现）

> 状态：**已实现**  
> API：`strategy=gc2`  
> 小程序 Tab：`gc2`（第 2 位 · 金叉二次突破）

---

## v2.0 两档规则（当前）

| 档位 | 大周期 MACD > 0 | 金叉周期（ref） | 突破条件 |
|------|----------------|----------------|---------|
| **短线 S** | 周 **或** 月 | 日 K 最近 MACD 金叉柱 | 当日 close > ref.high |
| **长线 B** | 月 **或** 年 | 周 K 最近 MACD 金叉柱 | 当周 close > ref.high |

- ref 与 signal **之间**至少 **2** 根完整 K（不含金叉柱与突破柱，`minBarsAfterRef = 2`）
- **中间 K 约束（v2.1）**：ref 与 signal 之间每一根 K 的 **close < ref.high**（曾收盘站上 ref.high 则不算二次突破）
- 现价过滤：`StockBase.close > ref.high`
- 原 v1.1 日/周/月三档、无大周期门槛、信号桶首破逻辑 **已废弃**

# 金叉二次突破策略设计（v1.1 · 历史定稿）

> 以下 v1.1 内容为历史设计存档

---

## 0. 命名（已定）

| 项 | 定稿 |
|----|------|
| **中文名** | **金叉二次突破** |
| **英文/代码** | `gc2`（golden cross phase-2 breakout） |
| **一句话** | MACD 金叉后，当前 K 收盘突破金叉 K 高点时介入 |

**取名理由**

- **金叉**：锚点 K 由 MACD 红柱金叉（`isIfRedGoldCross`）唯一定义，可量化。  
- **二次突破**：相对金叉策略「金叉当日入选」，本策略等金叉后的**第一次有效站上 ref High**。  
- 与 **梯子突破** 区分：梯子 ref = 背景内局部新高强 K；本策略 ref = **最近一次 MACD 金叉 K**。  
- 与 **回踩抬升** 区分：无需 L0-H1-L1 swing，仅两根锚点（金叉 K + 突破 K），规则更轻。  
- 与 **金叉策略 `qsn`** 区分：不要求大周期 MACD>0；入选时机是**突破日**而非金叉日。

---

## 1. 产品定义

### 1.1 统一叙事

```
命中 = Gate
     + 在 lookback 内找到「最近一次 MACD 金叉 K」→ ref
     + ref 与 signal 至少间隔 1 根完整 K（minBarsAfterRef ≥ 1）
     + 信号时间桶内，当前最新 K 为「第一根 close > ref.high」→ signal
     + 现价过滤：close > ref.high
```

> **不要求** 金叉后至信号前，中间 K 线的 `close ≤ ref.high`；中间曾站上 ref.high 再回落，不影响命中。

结构示意：

```
价格
  │     ref ─── MACD 金叉 K 的 High
  │      ╱╲
  │     ╱  ╲   （中间走势不限，可上可下）
  │    ╱    ╲
  │           signal ─── 信号桶内首根 close > ref.high，且须为当前最新 K
  └──────────────────────── 时间
```

小程序文案建议：**MACD 金叉 · 突破金叉高点**

### 1.2 与现有策略关系

| 策略 | 关系 |
|------|------|
| 金叉策略 `qsn` | **同源不同点**：同用日/周/月金叉，qsn 金叉即入选；gc2 等突破金叉高点 |
| 预判金叉 `preqsn` | 突破对象是「前一根 K」，非金叉 K |
| 梯子突破 `ladder` | 同为双 K 标记；ref 语义不同；现价过滤方向相反（见 §3.5） |
| 回踩抬升 `retest` | **替代方向**：gc2 用客观金叉 K 作锚，避免 swing 难量化问题 |

## 2. 三档参数总表（已定）

> **已定**：仅 **日 / 周 / 月** 三档金叉，**暂不要求** 周/月/年 MACD>0 大周期门槛。

| 配置项 | 短线 S | 中线 A | 长线 B |
|--------|--------|--------|--------|
| **金叉周期（ref）** | 日 K | 周 K | 月 K |
| **信号周期（signal）** | 日 K | 周 K | 月 K |
| **信号时间桶** | **当日**（含盘中已走完日 K） | **本周** | **本月** |
| **金叉定义** | 该周期 MACD **红柱金叉**（`isIfRedGoldCross`） | 同左 | 同左 |
| **ref 选取** | lookback 内 **最近一次** 金叉对应 K 线 | 同左 | 同左 |
| **lookback** | **60** 个交易日 | **52** 个交易周 | **24** 个自然月 |
| **最小间隔** | ref 与 signal 至少 **1** 根完整 K | 同左 | 同左 |
| **突破条件** | 信号 K：`close > ref.high` | 同左 | 同左 |
| **机会窗口** | **仅突破当日**有效；过后不再给机会 | **仅突破当周** | **仅突破当月** |
| **现价过滤** | `StockBase.close > signal.high` | 同左 | 同左 |
| **主图默认周期** | 日 K | 周 K | 月 K |

### 2.1 lookback 默认值（已定）

| 档位 | lookback | 说明 |
|------|----------|------|
| S | 60 个交易日 | 覆盖约 3 个月内最近金叉 |
| A | 52 个交易周 | 约 1 年 |
| B | 24 个自然月 | 约 2 年 |

参数键：`g2LookbackShort=60`、`g2LookbackMedium=52`、`g2LookbackLong=24`（编码默认值）。

## 3. 精确定义（可实现语义）

### 3.1 ref K（金叉 K）

1. 在操作周期（日/周/月）上取 MACD 序列（与 `UnilateralMacdTools` / `MACDIndicatorUtils` 一致）。  
2. 在 **lookback 窗口** 内，自近向远扫描，找到 **最近一根** 满足 `isIfRedGoldCross` 的 MACD 点。  
3. 将该点对应的 **Trade K 线** 记为 **ref**；`refDay = trade.day`，`refHigh = trade.high`。

若无金叉 → 该档不命中。

### 3.2 时间与间隔（已定）

- ref K 在时间上 **早于** 信号 K（不得同一根 K 既作 ref 又作 signal）。  
- **已定**：`minBarsAfterRef = 1`——ref 与 signal 之间至少间隔 **1 根完整 K**，避免「金叉翌日即破」过噪。  
- **不要求** 在 (ref, signal) 区间内逐根校验 `close ≤ ref.high`；金叉后中间 K 线可任意波动，甚至曾收盘站上 ref.high。

### 3.3 signal K（突破 K）

在 **信号时间桶** 内（与 [6.突破阶梯策略设计.md](./6.突破阶梯策略设计.md) §3.1 桶边界一致）：

1. 按时间正序扫描桶内 K 线；  
2. 找到 **第一根** 满足 `close > ref.high` 的 K → 候选 signal；  
3. **机会窗口（已定）**：仅当该候选 signal 即为 **当前评估时刻的最新已走完 K**（日档=今日、周档=本周、月档=本月）时命中；  
   - 若突破发生在昨日/上周/上月 → **不命中**（「仅突破当日才给机会，过后无机会」）。  
4. 突破判定 **仅用 close**（已定）：`signal.close > ref.high`；不要求 `high > ref.high` 单独成立，但以 close 为准。

### 3.4 Gate（硬门槛）

与仓库主流策略对齐，建议复用：

| # | 条件 |
|---|------|
| G1 | 在 `filterStockMap` 内 |
| G2 | 近 6 日平均成交额 ≥ `g2MinAmountWan`（默认 5000 万） |
| G3 | **月 MACD > 0** |
| G4 | 周或月未跌破近端支撑 Low |

### 3.5 现价过滤（已定）

```
StockBase.close > ref.high
```

含义：标的现价仍运行在 **金叉 K 高点** 之上（突破已确认）。  
注：signal K 为当日/当周/当月最新 K，`close` 不可能大于同根 K 的 `high`，故现价过滤锚定 **ref.high** 而非 `signal.high`。

### 3.6 多档同时命中

与金叉/梯子一致：

- 展示档位：S > A > B，取命中中最高优先级；  
- 受「最低展示档位」`g2TierMin` 过滤；  
- score：短线权重可略高于长线（具体分值编码时对齐 `UnilateralScoreCalculator` 量级）。

## 4. 信号消息与 K 线标记

建议与 ladder 对齐，便于小程序双点标记：

```
refDay=2025-04-15,refHigh=12.34,sigDay=2026-06-05,sigHigh=13.01,tier=S
```

| 标记 | 标签 | 含义 |
|------|------|------|
| ref | 金叉K | 最近一次 MACD 金叉 K |
| signal | 突破K | 信号桶内第一根 `close > ref.high` 的 K（须为当前最新 K） |

API 建议：

| 用途 | 路径 |
|------|------|
| 列表 | `GET /tts/stock/findMy?strategy=gc2&g2EnableShort=1&g2EnableMedium=1&g2EnableLong=1&...` |
| 重跑 | `POST /tts/stock/strategy/rescan?strategy=gc2&...` |
| 标记 | `GET /tts/stock/{code}/gc2/markers?period=day\|week\|month` |
