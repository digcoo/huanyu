# 短线策略（trend · v3）

> 状态：**已实现（逻辑层）**  
> API：`strategy=trend`（枚举名保留，展示名「短线策略」）

---

## 1. 产品定义

**一句话**：前 N 个自然周（默认 2）日 K 作基准，本周任一日 K 突破前 K 高且站在基准 Low 之上即可入选（结构与超短线对称，周期由 30m→日K、日桶→自然周桶）。

```
命中 = 前 N 自然周日K 存在基准K（A1 周内局部新高强K；若无则 A2 最近强K）
     + 本周日K 存在突破K（强K，close > 前K.high，close > ref.low，
       且 突破K.low 或 前K.close 至少其一 < ref.high）
     + **宏观底部强突破**：周K 在近 26 周区间分位 < 30% 时，还须 close > ref.high
     + 成交额 / 前周前月非大阴线（硬过滤）
     + 可选 MACD / 周金叉
     + **默认**：须同时满足超短 30m 突破（`trRequireUltra`，共用 `ul*` 参数）
```

---

## 2. 周期映射（相对超短线）

| 超短线 | 短线 |
|--------|------|
| 30m K | **日 K** |
| 分组：交易日 | 分组：**ISO 自然周** |
| 背景：前 2 日 | 背景：前 **2 周**（`trPrevWeeks` 可调 1–4） |
| 信号桶：当日 30m | 信号桶：**本周**日 K |

---

## 3. 基准K（ref）

- **窗口**：信号自然周之前的 `trPrevWeeks` 个完整周（默认 2）
- **强K**：实体或涨幅 ≥ 3%（默认）
- **A1**：每个自然周内，强 K 且 `high` 严格高于该周此前所有日 K 最高价；跨周取最后一根
- **A2**：自 signal 日前一根起向前，最近一根强 K

---

## 4. 突破K（signal）

- **窗口**：**本周**（当前 ISO 自然周）已走完的日 K
- **单根条件**：同超短线，操作对象改为日 K
- **命中规则**：
  - 默认：本周任意日 K 满足（多根取最后一根）
  - `trRequireCurrentBreakout=1`：仅**最新日 K**满足

---

## 5. 过滤与可选参数

| 参数 | 默认 | 说明 |
|------|------|------|
| 最低成交额 | 5000 万 | 近 6 日日均 |
| 基准背景周数 | **2** | 自然周，1–4 |
| 当前日K须为突破K | 关 | 开=仅当日 |
| 月/周/日 MACD>0 | 关 | 可选 |
| 周K MACD 金叉 | 关 | 可选 |
| 前周/前月非大阴线 | 5% / 10% | 硬过滤（写死） |
| **须超短 30m 突破** | **开** | `trRequireUltra`；30m 规则共用超短 Tab 的 `ul*` |

API：`trMinAmountWan`、`trPrevWeeks`、`trRequireCurrentBreakout`、`trRequireMonthMacd`、`trRequireWeekMacd`、`trRequireDayMacd`、`trRequireWeekGoldenCross`、`trRequireUltra`
