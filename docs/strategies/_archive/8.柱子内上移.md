# 柱子内上移（pillar）

> 状态：**已实现**  
> API：`strategy=pillar`  
> 展示名：**柱子内上移**

---

## 1. 产品定义

```
命中 = 双低支撑门 ∧ 无阻力 MACD 门 ∧ MACD 交叉 low 门   （固定，同 nrf / bogo / ultra）
     + 可选：近 6 日日均成交额 ≥ 门槛
     + 启用周期内任一档：强柱基准 ref + 当前 K 向上突破
     + 可选：须 min30 超短梯子（ul* 参数）
```

### 1.1 全局门控（固定）

见 `StrategyGlobalGateTools`：双低支撑门 + 无阻力 MACD 门 + **MACD 交叉 low 门**，日/周/月须全部满足。

### 1.2 强柱基准突破（可配周期）

| 参数 | 说明 | 默认 |
|------|------|------|
| `piEnableDay` | 日 K 联检 | 开 |
| `piEnableWeek` | 周 K 联检 | 关 |
| `piEnableMonth` | 月 K 联检 | 关 |
| `piLookbackDay/Week/Month` | 各周期向前扫描根数 | 60 / 52 / 36 |
| `piRequireUltra` | 须 min30 梯子 | 关 |
| `piMinAmountWan` | 近 6 日日均成交额（万）；0=不启用 | 0 |

**强 K 阈值**

| 周期 | ref 基准（仅大实体） | 当前 K（实体或涨幅） |
|------|---------------------|----------------------|
| 日 K | ≥ 2% | ≥ 2% |
| 周 K | ≥ 3% | ≥ 3% |
| 月 K | ≥ 5% | ≥ 5% |

单周期逻辑：

1. 自当前 K 向前（不含当前 K），在 lookback 内枚举候选 **ref**
2. **ref**：大阳线实体 ≥ 阈值；ref 与当前 K 之间（不含二者）每根 `close < ref.high`；`prev.close ≤ ref.high`
3. **当前 K**：`close > prev.high` 且 `close > ref.low` 且 `min(cur.low, prev.close) < ref.high` 且为强 K
4. **任一 ref 配对命中即该周期命中**；展示取 **离当前 K 最近** 的 ref
5. 多周期 OR：任一启用周期命中即入池；展示月 > 周 > 日

## 3. 消息格式

- **趋势**：`[PILLAR]柱子内上移|日周月双低支撑门|日周月无阻力MACD门|日K强柱基准突破`
- **信号**：`突破基准K,period=day,refDay=...,refHigh=...,sigDay=...,sigClose=...`

---

## 4. 与梯子 / bogo 区别

| 维度 | 梯子 trend | bogo | pillar |
|------|------------|------|--------|
| ref | 背景桶 + 局部新高强K | 最近 MACD 交叉 K | **强柱 + 中间 close 全 < ref.high** |
| ref 数量 | 1 | 1 | **多个，任一命中** |
| 信号 K | 信号桶内任一根 | 当前 K | **当前 K** |
| min30 | 可选（trend 默认开） | 无 | **可选，默认关** |
| 成交额 | 有 | 无 | **可选** |
