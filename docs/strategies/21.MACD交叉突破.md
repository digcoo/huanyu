
# 同档 MACD 交叉突破（macdcrosstier）

> 状态：**已实现**  
> API：`strategy=macdcrosstier` + `mctTier=day|week|month`  
> 展示名：**MACD交叉突破**（短线日档 / 中线周档 / 长线月档）

---

## 1. 产品定义

三档独立评估，每次请求只评一个档位（由 `mctTier` 指定）。核心逻辑与 `macedge` 单档边沿突破一致，但**不叠加可选六门**，且**每次仅评一个周期**。

### 1.1 命中条件（三路径并集）

在当前档位 K 序列中，以下**任一路径**命中即可（优先级：金叉K突破 → 死叉K突破 → 金叉上涨率）：

| 路径 | 条件 |
|------|------|
| **金叉K突破** | 最近一根金叉 K（不含信号K）为基准，信号K边沿突破该金叉K的 high |
| **死叉K突破** | 最近一根死叉 K（不含信号K）为基准，信号K边沿突破该死叉K的 high |
| **金叉上涨率** | 当前K为 MACD 金叉，且上涨率 > 3%（`(close-前收)/前收`，三档共用） |

**并集门控**（命中任一路径后均须满足）：

1. **本档末 K** 的 close > **前 K** 的 high（三档共用）
2. 日档附加：周、月收盘价 > 各周期末波段底
3. 三档共用：周/月凹凸形态门

边沿突破统一定义：前 K 收盘 ≤ 突破线，且信号 K 收盘 > 突破线；信号 K 不得与基准交叉 K 为同一根。

各路径在 lookback 内**由近及远**搜索最近一根**符合该路径类型**的交叉 K（跳过信号 K）；例如仅死叉时跳过更近的金叉，继续向前找死叉 K。

### 1.2 基准交叉 K 类型（可选关闭某突破路径）

| 参数 | 默认 | 说明 |
|------|------|------|
| `mctEnableGoldenCross` | **true** | 启用金叉K突破路径 |
| `mctEnableDeathCross` | **true** | 启用死叉K突破路径 |
| `mctEnableGoldenCrossRiseGate` | **true** | 启用当前金叉+上涨率路径 |
| `mctSignalRisePct` | **0.03** | 金叉上涨率阈值（三档共用） |

### 1.3 日档附加门（仅短线）

日档 MACD 交叉突破命中后，还须同时满足：

| 周期 | 条件 |
|------|------|
| **周 K** | 周收盘价 > 周末完整波段的波段底（首阳 low） |
| **月 K** | 月收盘价 > 月末完整波段的波段底（首阳 low） |

### 1.4 周/月凹凸形态门（三档共用）

短线、中线、长线均须**同时**满足周、月末两波段形态门：

| 末波段形态 | 周 / 月条件 |
|------------|-------------|
| **凹波段** | 收阳，且当前价（收盘价）> 末波段 high |
| **凸波段** | 收阳，且当前价（收盘价）> 同档前 K high |

### 1.5 档位与 lookback

| 档位 | 评估周期 | 默认 lookback |
|------|----------|---------------|
| **短线（日）** | 日 K | `mctLookbackDay` = 60 |
| **中线（周）** | 周 K | `mctLookbackWeek` = 52 |
| **长线（月）** | 月 K | `mctLookbackMonth` = 36 |

### 1.6 与 macedge 的区别

| 维度 | macdcrosstier | macedge |
|------|---------------|---------|
| 档位 | 单档（日/周/月三选一） | 多档并集（Min30/日/周/月/年可勾选） |
| 可选六门 | 无 | 有（双低、死叉高、全阳等） |
| 成交额过滤 | 无 | 可选 |

## 2. API

```
GET /stock/findMy?strategy=macdcrosstier&mctTier=day&all=1&...

```
