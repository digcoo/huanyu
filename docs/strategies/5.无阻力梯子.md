# 无阻力梯子（nrf · v2）

> 状态：**已实现**  
> API：`strategy=nrf`  
> 展示名：**无阻力梯子**

---

## 1. 产品定义

**一句话**：在梯子策略（短 / 中 / 长任一档）之上，叠加固定的日、周、月三周期 MACD 门。

```
命中 = 日 MACD 门 ∧ 周 MACD 门 ∧ 月 MACD 门
     + 当前档位梯子逻辑（与梯子策略完全相同）
     + 可选 requireUltra（与梯子一致，超短参数沿用 ultra 存储）
```

### 1.1 无阻力 MACD 门（固定，三周期同时满足）

对 **日 K、周 K、月 K** 各自独立判定：

```
通过 = MACD > 0
    OR (MACD ≤ 0 AND 当前K.close > 前K.high)
```

MACD 柱取值与现有 `UnilateralMacdTools` 一致（最新一根 K 对应 MACD 柱）。

### 1.2 梯子档位（固定联检 min30）

| 档位 `nrfActiveTier` | 联检内容 | 主图周期 |
|----------------------|----------|----------|
| `short` | **日 K 梯子 + min30 梯子** | 日 K |
| `medium` | **周 K 梯子 + min30 梯子** | 周 K |
| `long` | **月 K 梯子 + min30 梯子** | 月 K |

- 三档均 **强制** 联检 30m 超短梯子（`requireUltra` 不可关闭）。
- 日/周/月梯子参数 schema 与梯子策略对应档相同（`tr*` / `md*` / `lg*`）。
- 档位内的 MACD / 金叉开关在服务端 **忽略**（由固定三门替代）。
- 30m 参数沿用「超短」Tab 存储。

---

## 2. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=nrf&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=nrf&...` | 写库扫描 |

### 策略专属参数

| 字段 | 说明 | 默认 |
|------|------|------|
| `nrfActiveTier` | `short` / `medium` / `long` | `short` |

其余：当前档位对应的 `tr*` / `md*` / `lg*`；若开启 `requireUltra`，另附 `ul*`。

---

## 3. 消息格式

- **趋势**：`[NRF]日+min30梯子|日周月无阻力MACD门|…`（中/长为 `周+min30梯子` / `月+min30梯子`）
- **信号**：与对应档位梯子策略相同（含 `refDay` / `sigDay`）

### 3.1 K 线标记

与梯子策略相同：按 **当前档位** 在对应周期展示基准 K / 突破 K（短→日 K，中→周 K，长→月 K）。

---

## 4. 小程序 UI

参数均在 **⚙ 参数面板** 内配置：

- 顶部 **日+min30 / 周+min30 / 月+min30** 分档 Tab
- 无阻力策略额外展示 **MACD 门说明** section
- 首页不展示参数摘要或档位切换

---

## 5. 与梯子策略区别

| 维度 | 梯子策略（ladder） | 无阻力梯子（nrf） |
|------|-------------------|-------------------|
| API | `strategy=trend\|medium\|long` | `strategy=nrf` |
| MACD | 各档可选 | **固定三门**（日/周/月） |
| 档位 | 短 / 中 / 长 | 短 / 中 / 长（相同） |
| 参数存储 | `ladder` key | `nrf` key（结构相同） |
