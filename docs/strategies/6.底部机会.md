# 底部机会（bogo）

> 状态：**已实现**  
> API：`strategy=bogo`  
> 展示名：**底部机会**

---

## 1. 产品定义

```
命中 = 日 MACD 门 ∧ 周 MACD 门 ∧ 月 MACD 门   （同无阻力梯子，固定）
     + 启用周期内任一档：最近金叉/死叉 K 为基准，现价突破基准 K 高点
```

### 1.1 无阻力 MACD 门（固定）

与 `nrf` 相同：日/周/月三周期各自

```
通过 = MACD > 0 OR (MACD ≤ 0 AND 当前K.close > 前K.high)
```

### 1.2 金叉/死叉基准突破（可配周期）

| 参数 | 说明 |
|------|------|
| `boEnableDay` | 日 K 联检 |
| `boEnableWeek` | 周 K 联检 |
| `boEnableMonth` | 月 K 联检 |
| `boLookbackDay/Week/Month` | 各周期向前搜索金叉/死叉的最大 K 数 |

单周期逻辑：

1. 自最新 K 向前，取**最近一根** MACD 红柱金叉 **或** 绿柱死叉 K 为基准 K（**不得与当前 K 同一根**）
2. **前一根 K** 的 close ≤ 基准 K 的 high（尚未突破）
3. **当前 K** 的 close > 基准 K 的 high（本根首次突破）

多周期同时开启时，**任一**启用周期命中即入池；展示取月 > 周 > 日优先级。

## 2. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=bogo&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=bogo&...` | 写库扫描 |
| `GET /stock/{code}/bogo/markers?period=day\|week\|month` | K 线标记 |

---

## 3. 消息格式

- **趋势**：`[BOGO]底部机会|日周月无阻力MACD门|日K金叉基准突破`（周/月同理）
- **信号**：`突破基准K,crossType=GC|DC,period=day,refDay=...,refHigh=...,sigDay=...,sigClose=...`

---

## 4. 与 gc2 区别

| 维度 | gc2 | bogo |
|------|-----|------|
| 门控 | 大周期 MACD>0 + 成交额 | **固定无阻力三门** |
| 基准 K | 仅金叉 | **金叉或死叉（取最近，且非当前 K）** |
| 突破定义 | close > refHigh | **前 K close ≤ refHigh，当前 K close > refHigh** |
| 中间 K 约束 | 须全部 close < refHigh | **无** |
| 周期 | 日/周两档 | **日/周/月可选** |
