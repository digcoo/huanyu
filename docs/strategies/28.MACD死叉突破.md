
# MACD死叉突破（macddcb）

> 状态：**已实现**  
> API：`strategy=macddcb` + `mdcbTier=day|week|month`  
> 展示名：**MACD死叉突破**（短线日档 / 中线周档 / 长线月档）

---

## 1. 产品定义

### 1.1 必选条件

1. **本档 MACD 柱 < 0**（末 K）。
2. 最近 MACD 交叉（lookback 内）须为**死叉**。
3. **同档边沿突破**死叉 K **前一根 K 的 high**：
   - 末 K `close > refHigh`
   - 前 K `close ≤ refHigh`
   - 其中 `refHigh` = 死叉 K 前一根 K 的 `high`

### 1.2 可选配置

| 参数 | 默认 | 说明 |
|------|------|------|
| `mdcbEnableMinAmountFilter` | **true** | 近 6 日日均成交额门 |
| `mdcbMinAmountWan` | 3000 | 最低日均成交额（万） |
| `mdcbEnableSignalRiseGate` | **true** | 末 K 上涨率门 |
| `mdcbSignalRisePct` | 3 | 末 K 上涨率阈值（%） |

---

## 2. API 示例

```
GET /stock/findMy?strategy=macddcb&mdcbTier=week&all=1&page=1&size=12
```

---

## 3. 与同系列策略区别

| | **macddcb** | **macdgcwh** | **macedge 死叉K突破** |
|--|-------------|--------------|----------------------|
| MACD | 末 K < 0 | 末 K > 0 | 无硬性要求 |
| 突破线 | 死叉K**前一根** high | 波段 bandHigh | 死叉 K high |
| 交叉类型 | 须为死叉 | 须为金叉 | 可选 |
