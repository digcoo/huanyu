# 凹波段突破（waveconcave）

> 状态：**已实现**  
> API：`strategy=waveconcave`  
> 展示名：**凹波段同档突破**（Tab 简称：**凹同档**）  
> 说明：末两阳波段形态为凹（末阳 high 未抬升），同档 K 边沿突破

---

## 1. 产品定义

```
命中 = 日/周/月须同时满足：本档 close > 本档末完整波段末阳底
     + [可选] 全阳门 ∧ Min30 突破门 ∧ 近 6 日日均成交额 ≥ 门槛（默认均关闭）
     + 启用档位内任一档满足凹波段同档突破（多档并集）
```

### 1.0 日周月末阳底上方（硬性）

与 [9.凸波段突破.md](./9.凸波段突破.md) §1.0 相同。

### 1.1 凸/凹形态判定

与 [9.凸波段突破.md](./9.凸波段突破.md) §1.1 相同；本策略仅匹配**凹波段**。

### 1.2 突破线（三选一，均可配置）

| 参数 | 突破线 |
|------|--------|
| 均未开启 | **默认** 末阳顶 `lastYang.high` |
| `wccEnableLastHighBreak=开` | 末阳顶 `lastYang.high` |
| `wccEnableLastMedianBreak=开` | 末阳中位价 `(high+low)/2` |
| `wccEnableLastLowBreak=开` | 末阳底 `lastYang.low` |

多参数同时开启时优先级：**末阳底 > 末阳中位 > 末阳顶**。

### 1.3 同档 K 边沿突破

与 [9.凸波段突破.md](./9.凸波段突破.md) §1.3 相同。

### 1.4 可选全局门（默认关）

| 参数 | 默认 | 说明 |
|------|------|------|
| `wccEnableAllYangGate` | 关 | 日/周/月最后一根 K 均为阳线 |
| `wccEnableMin30Gate` | 关 | 30m 跨日桶柱内突破 |
| `wccMinAmountWan` | 0 | 近 6 日日均成交额（万）；0=不启用 |

### 1.5 档位参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `wccEnableDay/Week/Month` | **日开** / 周关 / 月关 | 启用档位 |
| `wccLookbackDay/Week/Month` | 60 / 52 / 36 | 各周期波段扫描回溯 |

## 2. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=waveconcave&all=1&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=waveconcave&...` | 写库 |
| `GET /stock/{code}/waveconcave/markers?period=day\|week\|month` | K 线标记 |

---

## 3. 信号格式

趋势前缀：`[WAVECONCAVE]凹波段突破|日周月末阳底上方|...`

信号示例：

```
凹波段突破,bandShape=CONCAVE,breakPath=LAST_HIGH,signalTier=day,refPeriod=day,
lastYangDay=...,lastMedian=...,lastHigh=...,lastLow=...,prevLastYangHigh=...,breakLine=...,
bandHigh=...,bandLow=...,sigDay=...,sigClose=...,prevDay=...,prevClose=...
```

---

## 4. 与凸波段对比

| 维度 | 凸波段 `waveconvex` | 凹波段 `waveconcave` |
|------|---------------------|----------------------|
| 形态 | 末阳 high > 前波段末阳 high | 否则 |
| 默认突破线 | 末阳中位 | 末阳顶 |
| 可选替代 | 末阳顶 | 末阳中位 |
| 硬性门 | 日周月末阳底上方 | 相同 |
| 边沿 | 同档 K | 相同 |
