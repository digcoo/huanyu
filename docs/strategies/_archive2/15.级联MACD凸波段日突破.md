# 级联 MACD 凸波段日突破（cascadewaveconvexday）

> 状态：**已实现**  
> API：`strategy=cascadewaveconvexday`  
> 展示名：**级联 MACD 凸波段日突破**（Tab 简称：**级联凸日**）

---

## 1. 产品定义

在级联凸同档策略（文档 13）基础上，**边沿改为统一日 K**：

```
上一根日 K：close ≤ 突破线
当前日 K：close > 突破线
```

无论信号来自日/周/月哪一档波段，边沿均用最近两根日 K。其余规则相同：

- 级联 MACD 柱 > 0（日→周→月→年）；级联档最后一根 K 不得为 MACD 金叉柱（规则同文档 13 §1.1）
- 无末阳底硬性门
- 突破线固定末波段末阳 high；可选前波段末阳 high（OR）
- 可选全阳门 / Min30 门 / 成交额门槛

参数前缀：`cwcvd*`

---

## 2. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=cascadewaveconvexday&all=1&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=cascadewaveconvexday&...` | 写库 |
| `GET /stock/{code}/cascadewaveconvexday/markers?period=day` | K 线标记 |

信号含 `edgeMode=DAY`、`refPeriod=day`。
