# MACD 交叉边沿突破（macedge）

> 状态：**已实现**  
> API：`strategy=macedge`  
> 展示名：**MACD 交叉边沿突破**（Tab 简称：**MACD 边沿**）  
> 说明：各档 MACD 交叉 K 为基准，同档最后一根 K 边沿突破基准 high（无级联确认）

---

## 1. 产品定义

```
命中 = [可选] 双低支撑门 ∧ 无阻力 MACD 门 ∧ MACD 死叉高门 ∧ MACD 交叉 low 门 ∧ 高点递进门 ∧ 全阳门（死叉高门、全阳门默认开）
     + [可选] 近 6 日日均成交额 ≥ 门槛（默认 3000 万；0=不启用）
     + 启用档位内任一档满足边沿突破（多档勾选取并集）
```

### 1.1 可选六门

| 参数 | 默认 | 说明 |
|------|------|------|
| `meEnableDualLowGate` | 关 | 双低支撑门 |
| `meEnableMacdGate` | 关 | 无阻力 MACD 门 |
| `meEnableMacdDcHighGate` | **开** | MACD 死叉高门：MACD>0，或 MACD≤0 且本档 close>最近 MACD 死叉 K.high；日/周/月须全部满足 |
| `meEnableCrossLowGate` | 关 | MACD 交叉 low 门 |
| `meEnableBarHighGate` | 关 | 高点递进门 |
| `meEnableAllYangGate` | **开** | 全阳门：日、周、月、年最后一根 K 均为阳线 |

六门均关闭时不做门控。

### 1.2 基准 K

各周期 lookback 内**最近一根 MACD 金叉或死叉 K**（**非当前 K**）为基准 K，取 **high** 为突破线。

### 1.3 边沿突破（同档 K）

**边沿突破 K 与基准档位同周期**：

```
最后一根本档 K：close > 基准 K.high
倒数第二根本档 K：close ≤ 基准 K.high
```

| 档位 | 基准周期 | 边沿突破周期 |
|------|----------|--------------|
| Min30 | Min30 MACD 交叉 K | 最后一根 **Min30** K |
| 日 | 日 K MACD 交叉 K | 最后一根 **日** K |
| 周 | 周 K MACD 交叉 K | 最后一根 **周** K |
| 月 | 月 K MACD 交叉 K | 最后一根 **月** K |
| 年 | 年 K MACD 交叉 K | 最后一根 **年** K |

多档同时勾选时，各档独立判定，**任一档命中即入池**（并集）。

### 1.4 与 cascade 区别

| 维度 | cascade | macedge |
|------|---------|---------|
| 边沿突破 K | **统一日 K** | **各档同周期 K** |
| 档位 | 日 / 周 / 月 | Min30 / 日 / 周 / 月 / 年 |
| 级联确认 | 有 | **无** |
| 备选路径 B | 可选 | **无** |

### 1.5 其他参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `meEnableMin30/Day/Week/Month/Year` | Min30关 / **日开** / 周月年关 | 启用档位 |
| `meLookbackMin30/Day/Week/Month/Year` | 50 / 60 / 52 / 36 / 20 | 各周期交叉 K 回溯 |

## 2. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=macedge&all=1&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=macedge&...` | 写库 |
| `GET /stock/{code}/macedge/markers?period=min30\|day\|week\|month\|year` | K 线标记 |

## 3. 消息格式

- **趋势**：`[MACEDGE]MACD交叉边沿突破|可选六门|日K基准边沿突破`（示例）
- **信号**：`MACD交叉边沿突破,crossType=GC,signalTier=day,refPeriod=day,refDay=...,refHigh=...,sigDay=...,sigClose=...,prevDay=...,prevClose=...`
