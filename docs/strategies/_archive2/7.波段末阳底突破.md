# 波段末阳底突破（wavelow）

> 状态：**已实现**  
> API：`strategy=wavelow`  
> 展示名：**波段末阳底突破**（Tab 简称：**末阳底**）  
> 说明：各档 lookback 内末完整阳波段，**仅末阳底**为突破线，统一日 K 边沿突破

---

## 1. 产品定义

```
命中 = 日/周/月须同时满足：本档最后一根 K 的 close > 本档 lookback 内末完整波段的末阳 K.low
     + [可选] 六门（默认死叉高门、全阳门开）
     + [可选] 近 6 日日均成交额 ≥ 门槛（默认 3000 万；0=不启用）
     + 启用档位内任一档满足末阳底边沿突破（多档并集）
```

### 1.0 日周月末阳底上方（硬性）

```
本档最后一根 K：close > 本档 lookback 内末完整阳波段的末阳 K.low
```

### 1.1 可选六门

与 wavelow 六门、硬性末阳底门相同，参数前缀 `wl*`。

### 1.2 完整阳波段

末完整阳波段定义见 §1.2。

### 1.3 突破线：仅末阳底

| 路径 | 突破线 |
|------|--------|
| `LAST_LOW` | 末阳 K 的 `low` |

**不做**首阳/末阳中位并集。

### 1.4 日 K 边沿突破（各档统一）

```
昨日 close ≤ 末阳底
今日 close > 末阳底
```

且今日日 K 不能是该档末波段的最后一根阳 K。

### 1.5 其他参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `wlEnableDay/Week/Month` | **日开** / 周关 / 月关 | 启用档位 |
| `wlLookbackDay/Week/Month` | 60 / 52 / 36 | 各周期波段扫描回溯 |
| `wlMinAmountWan` | 3000 | 近 6 日日均成交额（万）；0=不启用 |

---

## 2. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=wavelow&all=1&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=wavelow&...` | 写库 |
| `GET /stock/{code}/wavelow/markers?period=day\|week\|month` | K 线标记（referenceHigh=末阳底价线） |

---

## 3. 与其他波段策略区别

| 维度 | wavelow | waveconvex |
|------|---------|------------|
| 突破线 | **仅末阳底** | 凸/凹形态 + 中位或顶 |
| 硬门槛 | **末阳底上方** | 末阳底上方 |
| 边沿 K | 统一日 K | 同档 K |
