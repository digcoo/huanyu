# 凸波段突破（waveconvex）

> 状态：**已实现**  
> API：`strategy=waveconvex`  
> 展示名：**凸波段同档突破**（Tab 简称：**凸同档**）  
> 说明：末两阳波段形态为凸（末阳 high 抬升），同档 K 边沿突破

---

## 1. 产品定义

```
命中 = 日/周/月须同时满足：本档 close > 本档末完整波段末阳底
     + [可选] 全阳门 ∧ Min30 突破门 ∧ 近 6 日日均成交额 ≥ 门槛（默认均关闭）
     + 启用档位内任一档满足凸波段同档突破（多档并集）
```

### 1.0 日周月末阳底上方（硬性）

日 K、周 K、月 K **须全部满足**（与突破档位勾选无关）：

```
本档最后一根 K：close > 本档 lookback 内末完整阳波段的末阳底 low
```

### 1.1 凸/凹形态判定

在 lookback 内取**最后两个**完整阳波段：

```
末波段末阳 high > 前波段末阳 high  → 凸波段（waveconvex）
否则                               → 凹波段（waveconcave，见文档 10）
```

### 1.2 突破线（三选一，均可配置）

| 参数 | 突破线 |
|------|--------|
| 均未开启 | **默认** 末阳中位价 `(high+low)/2` |
| `wcvEnableLastHighBreak=开` | 末阳顶 `lastYang.high` |
| `wcvEnableLastMedianBreak=开` | 末阳中位价 `(high+low)/2` |
| `wcvEnableLastLowBreak=开` | 末阳底 `lastYang.low` |

多参数同时开启时优先级：**末阳底 > 末阳中位 > 末阳顶**。

### 1.3 同档 K 边沿突破

```
上一根同档 K：close ≤ 突破线
当前同档 K：close > 突破线
```

且当前 K 不能是该档末波段的最后一根阳 K。

### 1.4 可选全局门（默认关）

| 参数 | 默认 | 说明 |
|------|------|------|
| `wcvEnableAllYangGate` | 关 | 日/周/月最后一根 K 均为阳线 |
| `wcvEnableMin30Gate` | 关 | 30m 跨日桶柱内突破（超短引擎默认参数） |
| `wcvMinAmountWan` | 0 | 近 6 日日均成交额（万）；0=不启用 |

### 1.5 档位参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `wcvEnableDay/Week/Month` | **日开** / 周关 / 月关 | 启用档位 |
| `wcvLookbackDay/Week/Month` | 60 / 52 / 36 | 各周期波段扫描回溯 |

## 2. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=waveconvex&all=1&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=waveconvex&...` | 写库 |
| `GET /stock/{code}/waveconvex/markers?period=day\|week\|month` | K 线标记 |

---

## 3. 信号格式

趋势前缀：`[WAVECONVEX]凸波段突破|日周月末阳底上方|...`

信号示例：

```
凸波段突破,bandShape=CONVEX,breakPath=LAST_MEDIAN,signalTier=day,refPeriod=day,
lastYangDay=...,lastMedian=...,lastHigh=...,lastLow=...,prevLastYangHigh=...,breakLine=...,
bandHigh=...,bandLow=...,sigDay=...,sigClose=...,prevDay=...,prevClose=...
```
