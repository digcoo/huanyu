# 波段同档末阳底突破（wavetierlow）

> 状态：**已实现**  
> API：`strategy=wavetierlow`  
> 展示名：**波段同档末阳底突破**（Tab 简称：**同档底**）  
> 说明：各档末完整阳波段，**仅末阳底**为突破线，**同档 K 边沿突破**

---

## 1. 产品定义

```
命中 = 日/周/月须同时满足：本档最后一根 K 的 close > 本档 lookback 内末完整波段的末阳 K.low
     + [可选] 六门（默认死叉高门、全阳门开）
     + [可选] 近 6 日日均成交额 ≥ 门槛（默认 3000 万；0=不启用）
     + 启用档位内任一档满足同档末阳底边沿突破（多档并集）
```

### 1.0 日周月末阳底上方（硬性）

与 [7.波段末阳底突破.md](./7.波段末阳底突破.md) §1.0 相同。

### 1.1 可选六门

参数前缀 `wtl*`，规则同 wavelow（六门 + 末阳底硬性门）。

### 1.2 完整阳波段

末完整阳波段定义见 [7.波段末阳底突破.md](./7.波段末阳底突破.md) §1.2。

### 1.3 突破线：仅末阳底

仅 `LAST_LOW = 末阳 K.low`。

### 1.4 同档 K 边沿突破

| 档位 | 边沿突破周期 |
|------|--------------|
| 日 | 最后一根 **日** K |
| 周 | 最后一根 **周** K |
| 月 | 最后一根 **月** K |

```
最后一根本档 K：close > 末阳底
倒数第二根本档 K：close ≤ 末阳底
```

且信号 K 不能是该档末波段的最后一根阳 K。

### 1.5 其他参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `wtlEnableDay/Week/Month` | **日开** / 周关 / 月关 | 启用档位 |
| `wtlLookbackDay/Week/Month` | 60 / 52 / 36 | lookback |
| `wtlMinAmountWan` | 3000 | 成交额门槛（万） |
