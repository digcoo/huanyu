# 凸波段日突破（waveconvexday）

> 状态：**已实现**  
> API：`strategy=waveconvexday`  
> 展示名：**凸波段日突破**（Tab 简称：**凸日**）  
> 说明：末两阳波段形态为凸（末阳 high 抬升），**统一日 K 边沿**突破（与 `waveconvex` 同档边沿相对）

---

## 1. 产品定义

```
命中 = 日/周/月须同时满足：本档 close > 本档末完整波段末阳底
     + [可选] 全阳门 ∧ Min30 突破门 ∧ 近 6 日日均成交额 ≥ 门槛（默认均关闭）
     + 启用档位内任一档满足凸波段日 K 边沿突破（多档并集）
```

形态、突破线（`wcvdEnableLastHighBreak` / `wcvdEnableLastMedianBreak` / `wcvdEnableLastLowBreak`，默认均未开）、硬性末阳底门与 [9.凸波段突破.md](./9.凸波段突破.md) 相同（参数前缀 `wcvd*`）；**边沿**改为：

### 1.1 日 K 边沿突破

无论信号来自日/周/月哪一档波段，边沿统一用**最近两根日 K**：

```
上一根日 K：close ≤ 突破线
当前日 K：close > 突破线
```

且当前日 K 不能是该档末波段的最后一根阳 K。

---

## 2. API

| 接口 | 说明 |
|------|------|
| `GET /stock/findMy?strategy=waveconvexday&all=1&...` | 预览 |
| `POST /stock/strategy/rescan?strategy=waveconvexday&...` | 写库 |
| `GET /stock/{code}/waveconvexday/markers?period=day\|week\|month` | K 线标记 |

参数前缀：`wcvd*`（与 `wcv*` 独立存储）。

---

## 3. 信号格式

趋势前缀：`[WAVECONVEXDAY]凸波段日突破|日周月末阳底上方|...`

信号示例：

```
凸波段日突破,bandShape=CONVEX,breakPath=LAST_MEDIAN,signalTier=day,refPeriod=day,...
```
