
# 级联 MACD 凸波段突破（cascadewaveconvex）

> 状态：**已实现**  
> API：`strategy=cascadewaveconvex`  
> 展示名：**级联 MACD 凸波段同档突破**（Tab 简称：**级联凸**）  
> 说明：末两阳波段形态为凸 + 级联 MACD 柱 > 0，同档 K 边沿突破末波段末阳顶

---

## 1. 产品定义

```
命中 = [可选] 全阳门 ∧ Min30 突破门 ∧ 近 6 日日均成交额 ≥ 门槛（默认均关闭）
     + 启用档位内任一档满足：级联 MACD 柱 > 0 + 凸波段同档突破（多档并集）
```

**无**「日周月末阳底上方」硬性门（与凹凸四策略不同）。

### 1.1 级联 MACD 门

信号档与上一级档 MACD 柱均须 > 0；且**级联档最后一根 K 不得为 MACD 金叉柱**（`isIfRedGoldCross`）：

| 信号档 | 级联档 | 排除条件 |
|--------|--------|----------|
| 日 K | 周 K | 周 K 最后一根为 MACD 金叉 → 不命中 |
| 周 K | 月 K | 月 K 最后一根为 MACD 金叉 → 不命中 |
| 月 K | 年 K | 年 K 最后一根为 MACD 金叉 → 不命中 |

### 1.2 凸形态判定

在 lookback 内取**最后两个**完整阳波段：

```
末波段末阳 high > 前波段末阳 high  → 凸波段
```

### 1.3 突破线

固定为**末波段末阳 high**（凸凹相同）。

可选 `cwcvEnablePrevBandBreak`：开启后突破线可取**倒数第 2 波段末阳 high**，与末波段末阳 high 取 **OR** 并集。

### 1.4 同档 K 边沿突破

```
上一根同档 K：close ≤ 突破线
当前同档 K：close > 突破线
```

且当前 K 不能是该档末波段的最后一根阳 K。

### 1.5 可选全局门（默认关）

| 参数 | 默认 | 说明 |
|------|------|------|
| `cwcvEnableAllYangGate` | 关 | 日/周/月最后一根 K 均为阳线 |
| `cwcvEnableMin30Gate` | 关 | 30m 跨日桶柱内突破 |
| `cwcvMinAmountWan` | 0 | 近 6 日日均成交额（万）；0=不启用 |

### 1.6 档位参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `cwcvEnableDay/Week/Month` | **日开** / 周关 / 月关 | 启用档位 |
| `cwcvLookbackDay/Week/Month` | 60 / 52 / 36 | 各周期波段扫描回溯 |
| `cwcvLookbackYear` | **20** | 年 K 回溯（级联 MACD 月→年） |

## 3. 信号字段

`breakPath=LAST_BAND_HIGH` 或 `PREV_BAND_HIGH`；`breakLine` 为实际突破价。
