# 级联 MACD 凹波段突破（cascadewaveconcave）

> 状态：**已实现**  
> API：`strategy=cascadewaveconcave`  
> 展示名：**级联 MACD 凹波段同档突破**（Tab 简称：**级联凹**）  
> 说明：末两阳波段形态为凹 + 级联 MACD 柱 > 0，同档 K 边沿突破末波段末阳顶

---

## 1. 产品定义

```
命中 = [可选] 全阳门 ∧ Min30 突破门 ∧ 近 6 日日均成交额 ≥ 门槛（默认均关闭）
     + 启用档位内任一档满足：级联 MACD 柱 > 0 + 凹波段同档突破（多档并集）
```

**无**「日周月末阳底上方」硬性门。

### 1.1 级联 MACD 门

信号档与上一级档 MACD 柱均须 > 0（日→周、周→月、月→年）；且级联档最后一根 K 不得为 MACD 金叉柱（规则同文档 13 §1.1）。

### 1.2 凹形态判定

```
末波段末阳 high ≤ 前波段末阳 high  → 凹波段
```

### 1.3 突破线

固定为**末波段末阳 high**。

可选 `cwcavEnablePrevBandBreak`：前波段末阳 high 与末波段末阳 high 取 **OR** 并集。

### 1.4 同档 K 边沿突破

与级联凸相同：同档边沿突破，不做日 K 边沿。

### 1.5 可选全局门（默认关）

| 参数 | 默认 | 说明 |
|------|------|------|
| `cwcavEnableAllYangGate` | 关 | 全阳门 |
| `cwcavEnableMin30Gate` | 关 | Min30 突破门 |
| `cwcavMinAmountWan` | 0 | 成交额门槛 |

### 1.6 档位参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `cwcavEnableDay/Week/Month` | **日开** / 周关 / 月关 | 启用档位 |
| `cwcavLookbackDay/Week/Month` | 60 / 52 / 36 | 波段回溯 |
| `cwcavLookbackYear` | **20** | 年 K 回溯 |
