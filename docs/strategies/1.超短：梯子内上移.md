# 超短线策略（ultra · v1.0）

> 状态：**已实现（逻辑层）**  
> API：`strategy=ultra`  
> 后端枚举：`StrategyTypeEnum.ULTRA_SHORT`

---

## 1. 产品定义

**一句话**：前两交易日 30 分钟「局部新高强 K / 最近强 K」作基准，当日 30 分钟任一根强 K 突破前 K 高且收盘站在基准 Low 之上即可入选（多根满足取最后一根）。

```
命中 = 前两日 min30 存在基准K（A1 局部新高强K；若无则 A2 离 signal 最近强K）
     + 当日 min30 存在突破K（强K，close > 前K.high，close > 基准K.low，
       且 突破K.low 或 前K.close 至少其一 < 基准K.high）
     + **宏观底部强突破**：日K 在近 60 日区间分位 < 30% 时，还须 close > 基准K.high
```

---

## 2. 基准K（ref）

- **窗口**：信号日（今日）之前的 **2 个交易日** 内全部 30m K
- **强K**：大阳线 `(close-open)/open ≥ 2%` 或大涨幅 `≥ 2%`
- **选取（A1 + A2）**：
  - **A1 优先**：每个交易日内，强 K 且 `high` **严格高于**该日此前所有 30m K 的 `high`（当日局部新高）；跨日取**时间上最后一根**
  - **A2 回退**：若 A1 无候选，自 signal 日前一根起**向前**找**最近的一根强 K**
- **示例**：6/10 10:00 创 6/10 当日新高后，6/11 11:00 再创 6/11 当日新高 → ref 取 **6/11 11:00**（而非 6/10 绝对实体最大 K）

---

## 3. 突破K（signal）

- **窗口**：**当日** 已走完的 30m K（信号桶）
- **单根条件**（强K 且同时满足）：
  1. 强K（实体或涨幅 > 2%）
  2. `close > 前一根 K 的 high`（含跨至背景末根的前 K）
  3. `close > ref.low`
  4. `signal.low < ref.high` **或** `prev.close < ref.high`（突破前曾低于基准高点）
- **命中规则**：
  - **默认（关）**：当日**任意一根**满足即可（多根取最后一根作标记）
  - **当前K须为突破K（开）**：仅**最新一根** 30m K 满足上述条件时命中
- **说明**：中段（日K 区间分位 ≥ 30%）突破对象是**前 K 的 high**，不要求 `close > ref.high`；**底部**须同时 `close > ref.high`（强突破）

---

## 3.1 宏观位置过滤（底部强突破）

| 项 | 默认 |
|----|------|
| Context 周期 | **日 K** |
| 回看根数 | 60 |
| 底部阈值 | 区间分位 **< 30%** |
| 底部额外条件 | 突破K **`close > 基准K.high`** |
| 中段及以上 | 维持原规则（仅 `close > 前K.high`） |

分位：`positionPct = (最新日K.close − 区间Low) / (区间High − 区间Low)`，区间 High/Low 取回看窗口内各 K 极值。数据不足时不启用底部过滤。

## 4. 可选过滤（UI 自定义参数）

| 参数 | 默认 | 说明 |
|------|------|------|
| 最低成交额 | **5000 万** | 近 6 日日均成交额，滑动 1000–10000 万 |
| 月 MACD>0 | 关 | 开启后须满足 |
| 周 MACD>0 | 关 | 开启后须满足 |
| 日 MACD>0 | 关 | 开启后须满足 |
| 当前K须为突破K | **关** | 开=仅最新 30m K 满足突破条件时命中 |

API 查询字段：`ulMinAmountWan`、`ulRequireMonthMacd`、`ulRequireWeekMacd`、`ulRequireDayMacd`、`ulRequireCurrentBreakout`（0/1）
