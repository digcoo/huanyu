
# 凹凸突破（waveccbreak）

> 状态：**已实现**  
> API：`strategy=waveccbreak`  
> 展示名：**凹凸突破**（日/周/月档）

---

## 1. 产品定义

严格对应 `docs/my.md` 策略6，与旧版 `waveperiodgate` 独立；**凸波段突破线改为倒数第二波段 bandHigh**（非前 K high）。

### 1.1 形态与 MACD 分支

| 末波段 | MACD（信号 K） | 突破线 |
|--------|----------------|--------|
| 凸 | > 0 | 边沿突破 **倒数第二波段 bandHigh** |
| 凹 | > 0 | 边沿突破 **末波段 bandHigh** |
| 凸 | ≤ 0 | 边沿突破 **倒数第二波段 bandHigh** |
| 凹 | ≤ 0 | **无信号** |

边沿突破：`prev.close ≤ breakLine` 且 `signal.close > breakLine`。

### 1.2 可选配置

| 参数 | 默认 | 说明 |
|------|------|------|
| `wccbTier` | day | 档位：day / week / month（小程序短/中/长线） |
| `wccbEnableMinAmountFilter` | true | 近 6 日日均成交额门 |
| `wccbMinAmountWan` | 3000 | 最低日均成交额（万） |
| `wccbEnableSignalRiseGate` | true | 末 K 涨幅门 |
| `wccbSignalRisePct` | 3 | 末 K 涨幅阈值（%） |
| `mgRequireDayMacd` | false | 可选：日 MACD>0 |
| `mgRequireWeekMacd` | false | 可选：周 MACD>0 |
| `mgRequireMonthMacd` | false | 可选：月 MACD>0 |

> 注：本档信号 K 的 MACD 正负仍参与凸/凹分支（见 §1.1）；`mg*` 为**额外**多周期 MACD>0 过滤，与其他策略共用。

---

## 2. API 示例

```
GET /stock/findMy?strategy=waveccbreak&all=1&page=1&size=12
GET /stock/findMy?strategy=waveccbreak&wccbTier=week&wccbSignalRisePct=2
GET /stock/findMy?strategy=waveccbreak&mgRequireDayMacd=1&mgRequireWeekMacd=1
```

---

## 3. 与 waveperiodgate 区别

| | **waveccbreak** | **waveperiodgate** |
|--|-----------------|-------------------|
| 凸突破线 | 次波段 **bandHigh** | 前 K **high** |
| MACD≤0 | 仅凸可出信号 | 本档 MACD>0 门 |
| 上级周期 / 全阳 / max low 等 | 无 | 有 |
