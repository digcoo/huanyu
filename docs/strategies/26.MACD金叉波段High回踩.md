
# MACD金叉波段High回踩（macdgcwhr）

> 状态：**已实现**  
> API：`strategy=macdgcwhr` + `mgcwhrTier=day|week|month`  
> 展示名：**MACD金叉波段High回踩**（短线日档 / 中线周档 / 长线月档）

---

## 1. 产品定义

三档独立评估，每次请求只评一个档位（由 `mgcwhrTier` 指定）。

### 1.1 必选条件

1. **本档 MACD 柱 > 0**（末 K）。
2. 最近一根 MACD 交叉（不含信号 K 的搜索逻辑与 `macdgcwh` 一致）须为**金叉**。
3. 以金叉 K 定**基准完整阳波段**（与 `macdgcwh` 共用 `MacdGcWaveBandTools`）：
   - 金叉 K 为**阳 K**：取该 K 所属的完整阳波段（未完结则跳过）。
   - 金叉 K 为**阴 K**：从该阴 K 往前追溯最近一个完整阳波段（含以该阴 K 为完结 K 的波段）。
4. **末 K 收盘价 > 基准波段 bandHigh**（价在波段 High 上）。
5. **末 K low 贴近 bandHigh**：`|low - bandHigh| / bandHigh ≤ 0.01`（默认 1%）。

### 1.2 可选配置

| 参数 | 默认 | 说明 |
|------|------|------|
| `mgcwhrEnableMinAmountFilter` | **true** | 启用近 6 日日均成交额门 |
| `mgcwhrMinAmountWan` | 3000 | 最低日均成交额（万） |

### 1.3 金叉 K 回溯

与 `macdgcwh` 相同：日 60 / 周 52 / 月 36。

### 1.4 基准波段示例（阴 K 金叉）

**sh603077**（2026-07-15 阴 K 金叉）：基准波段为 **07-14（阳）~ 07-15（阴，完结 K）**，bandHigh = **2.39**（07-15 的 high），而非更早的 07-10 单阳波段（bandHigh = 2.20）。

---

## 2. API 示例

```
GET /stock/findMy?strategy=macdgcwhr&mgcwhrTier=day&all=1&page=1&size=12
```

---

## 3. 与 macdgcwh 的区别

| | **macdgcwhr** | **macdgcwh** |
|--|---------------|--------------|
| MACD | 须 > 0 | 无要求 |
| 价与波段 High | 已在 High **上** | 边沿**突破** High |
| 末 K | low 贴近 bandHigh（≤1%） | 边沿突破形态 |
| 信号 K 为金叉 | 允许 | 排除 |
