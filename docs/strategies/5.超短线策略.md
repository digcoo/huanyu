# 超短线策略（ulow · v3）

> API：`strategy=ulow`

## 命中条件

```
命中 = Gate
     + 前1~2日 30m 有大阳线/大涨幅(≥2%) 且 high 为区间新高(不含当日)
     + 当日 30m 有大阳线/大涨幅(≥2%) 且 high>前high 且 close>前bodyMax
     + 现价 ≤ 当日突破 min30 K 线的 high（避免追过突破高点）
```

### 前 1~2 日（背景）

扫描窗口内、**不含当日**的所有 30m K 线：

- **大阳线**：`close > open` 且 `(close-open)/open ≥ 2%`
- **大涨幅**：实体涨幅 ≥ 2%，或相对前收 `(close-prevClose)/prevClose ≥ 2%`
- 满足上述之一，且该 K 线 `high` = 前 1~2 日区间最高（新高）

### 当日（信号）

- 同样满足 **大阳线** 或 **大涨幅**（≥ 2%）
- `high >` 背景 K 线的 `high`
- `close >` 背景 K 线的 `bodyMax`（`max(open, close)`）
- 取当日**最新一根**满足条件的 30m（突破 K）

### 现价过滤（避免情绪耗尽）

- `StockBase.close ≤` 上述突破 K 的 `high`
- 允许贴 high（`=`），排除现价**高于**突破 K 高点的情况

### 扫描窗口

- **前 2 个交易日**（各最多 8 根）+ **当日**全部 30m

## 参数

| 参数 | 默认 |
|------|------|
| `lMin30BodyPct` | 0.02 |
| `lMin30PrevDays` | 2 |
| `lMin30BarsPerDay` | 8 |
