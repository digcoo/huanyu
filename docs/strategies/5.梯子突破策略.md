# 梯子突破策略（ladder · v2）

> API：`strategy=ladder`（兼容 `ulow`）  
> 小程序 Tab：`ladder`  
> **设计附录**（规则精确定义、样本推演、待定项）：[6.突破阶梯策略设计.md](./6.突破阶梯策略设计.md)

## 策略定位

**梯子突破** 为四档突破阶梯，与金叉/深跌等策略相同，在 **策略参数面板** 中开关周期档位：

| 档位 | 代号 | 基准周期 | 背景窗口 | 信号桶 |
|------|------|----------|----------|--------|
| **超短** | S | 30m | 前 2 交易日 | 当日 30m |
| **短** | A | 日K | 前 2 交易周 | 本周日K |
| **中** | B | 周K | 前 2 自然月 | 本月周K |
| **长** | C | 月K | 前 2 自然年 | 本年月K |

可多档同时启用；展示档位取命中中最高优先级 **S > A > B > C**，并受「最低展示档位」过滤。

**命中条件（四档共用）**：

```
Gate + 存在基准K + 存在突破K + 现价过滤（close ≤ 突破K.high）
```

详见设计附录 §1–§3。

## 小程序参数（⚙ 策略参数）

| 参数 | 说明 |
|------|------|
| `lEnableUltra/Short/Medium/Long` | 超短 / 短 / 中 / 长 开关 |
| `lTierMin` | 最低展示档位 ALL / C / B / A / S |
| `lMinAmountWan` | 最低日均成交额（万） |

修改档位或过滤后需 **重跑策略** 刷新列表。

## API

- 列表：`GET /tts/stock/findMy?strategy=ladder&lEnableUltra=1&lEnableShort=1&...`
- 重跑：`POST /tts/stock/strategy/rescan?strategy=ladder&...`
- 双 K 标记：`GET /tts/stock/{code}/ladder/markers?period=min30|day|week|month`  
  按当前图表周期返回该档 **基准K / 突破K** 时间戳；超短档对应 `min30`，短/中/长对应 `day/week/month`。
