## 策略1：MACD水上回踩后突破末波段Low，短中长线（日线、周线、月线）
[选股策略]:
1. macd > 0, 末波段与最后一根K之间的所有K线（包括最后一根K，不包括末波段中的任意一根K线），回踩过末波段的Low(即存在其中的某根K线的low <= 末波段的Low)，且末K的收盘价 > 末波段的Low，最后一根K收阳线，且末K收盘价 <= 末波段High 
2. 无论是哪个周期档位，日线末K必须收阳线(close >= open)

[可选配置]：
	最低日均成交额：默认3000万，可调整

1. 父级别底部位置
2. Min60MA之上
3. 父周期符合条件：
	水下：次波段High之上、前2根K的High之上
	水上：次波段探底回升、次波段未探底前High之上收阳(且 次波段High之上)
