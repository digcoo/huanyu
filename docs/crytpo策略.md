## 策略1：MA均线多头突破策略（4M），超短/短/中/长线（1小时）
[名词定义]:
-- MA7：本档周期下，7日均线。如周期为月，即7根月K的均线 
-- MA14：本档周期下，14日均线。如周期为月，即14根月K的均线 
-- MA28：本档周期下，28日均线。如周期为月，即28根月K的均线 
-- MA42：本档周期下，42日均线。如周期为月，即42根月K的均线 
-- MA多头排列：MA7 >= MA14 >= MA28 >= MA42
-- 多头均线关键K：首次走出多头排列的关键K；从后往前数，直到不满足该路径多头，即可找到关键K。例：按时间顺序K1、K2、K3，K3满足多头，K2满足多头，K1不满足，则K2为关键K；若仅K3满足，则K3为关键K。
-- 金叉交叉K：从后往前数，最后的那根MA7上穿MA14时的K线，并且必须在该路径多头均线关键K之后
-- 死叉交叉K：从后往前数，最后的那根MA7下穿MA14时的K线的前一根K线（MA7 >= MA14），并且必须在该路径多头均线关键K之后
-- 边沿突破：末K的close>基准K的High，末K的前一根K <= 基准K的High 

[选股策略]:
1. 符合该路径多头排列，且边沿突破金叉交叉K 或者 死叉交叉K 或者 多头均线关键K


## 策略2：MA均线空头跌破策略（4M），超短/短/中/长线（1小时）
[名词定义]:
-- MA7 / MA14 / MA28 / MA42：同上
-- MA空头排列：MA7 <= MA14<= MA28 <= MA42
-- 空头均线关键K：首次走上空头排列的关键K；从后往前数，直到不满足空头排列，即可找到关键K（规则对称多头）
-- 金叉交叉K：从后往前数，最后的那根MA7上穿MA14时的K线，并且必须在空头均线关键K之后
-- 死叉交叉K：从后往前数，最后的那根MA7下穿MA14时的K线的前一根K线（MA7 >= MA14），并且必须在空头均线关键K之后
-- 边沿跌破：末K的close<基准K的Low，末K的前一根K >= 基准K的Low 

[选股策略]:
1. 符合该路径空头排列，且边沿跌破死叉交叉K 或者 金叉交叉K 或者 空头均线关键K
