## 策略1：分时凹凸突破策略
0. 预定义概念：
[振幅率]：max((high - low) / low， (open - lastClose) / lastClose)

1. min60 macd >0、日macd > 0、周macd > 0，至少满足2个
2. min60 级别，满足以下二者其一：
	a. 满足凹波段边沿突破（突破末波段的High），突破K必须为最后一根min60周期K，且突破K满足以下任意条件：
		c1：突破K的振幅率> 突破K的前K的振幅率
		c2: 突破K的涨幅 > 1.5% 
	b. 满足凸波段边沿突破（突破次波段的High），突破K必须为最后一根min60周期K，且突破K满足以下任意条件：
		c1：突破K的振幅率> 突破K的前K的振幅率
		c2: 突破K的涨幅 > 1.5% 

3. 可选配置：
	最低日均成交额：默认3000万，可调整
	突破K的最低涨幅 > 1.5% ，可配置
	突破K：默认须末根 Min60 K；可改为当日任一根 Min60 满足即可

4. 止损：
	止损位1：波段High
	止损位2：突破K.low

## 策略3：趋势内凹凸突破策略
0. 预定义概念：
[振幅率]：max((high - low) / low， (open - lastClose) / lastClose)

1. 趋势周期：日macd > 0
2. 信号周期：min60 级别，且满足以下二者其一：
	a. 满足凹波段边沿突破（突破末波段的High），突破K必须为最后一根本周期K，且突破K满足以下任意条件：
		c1：突破K的振幅率> 突破K的前K的振幅率
		c2: 突破K的涨幅 > 1.5% 
	b. 满足凸波段边沿突破（突破次波段的High），突破K必须为最后一根本周期K，且突破K满足以下任意条件：
		c1：突破K的振幅率> 突破K的前K的振幅率
		c2: 突破K的涨幅 > 1.5% 

3. 可选配置：
	最低日均成交额：默认3000万，可调整
	突破K的最低涨幅 > 1.5% ，可配置
	趋势macd>0：日macd>0，周macd > 0，月macd > 0 ，可配置，全选取交集
	信号级别：小时级别、日信号级别、周级别，单选配置

4. 止损：
	止损位1：波段High
	止损位2：突破K.low	



## 策略5：趋势MA策略
1. 日 macd > 0 且 日close > max(日ma5, 日ma10， 日ma20， 日ma30) 且日线收阳、周macd > 0 且 周close > max(周ma5,  周ma10，  周ma20，  周ma30) 且周线收阳、月macd > 0 且 月close > max(月ma5,  月ma10， 月ma20， 月ma30) 且月线收阳，至少满足2个；

3. 可选配置：
	最低日均成交额：默认3000万，可调整

4. 止损：
	止损位1：波段High
	止损位2：突破K.low
