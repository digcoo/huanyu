## 策略1：MA均线多头突破基准K策略（3M = 3M1 ∨ 3M2），超短/短/中/长线（30分钟、日线、周线、月线）
[名词定义]:
-- MA5：本档周期下，5日均线。如周期为月，即5根月K的均线
-- MA10：本档周期下，10日均线。如周期为月，即10根月K的均线
-- MA20：本档周期下，20日均线。如周期为月，即20根月K的均线
-- MA30：本档周期下，30日均线。如周期为月，即30根月K的均线
-- 3M1多头排列：MA5 >= MA20 且 MA10 >= MA20
-- 3M2多头排列：MA5 >= MA30 且 MA10 >= MA30
-- 多头均线关键K：相对某一路径（3M1或3M2）首次走出多头排列的关键K；从后往前数，直到不满足该路径多头，即可找到关键K。例：按时间顺序K1、K2、K3，K3满足多头，K2满足多头，K1不满足，则K2为关键K；若仅K3满足，则K3为关键K。
-- 金叉交叉K：从后往前数，最后的那根MA5上穿MA10时的K线，并且必须在该路径多头均线关键K之后
-- 死叉交叉K：从后往前数，最后的那根MA5下穿MA10时的K线的前一根K线（MA5 >= MA10），并且必须在该路径多头均线关键K之后
-- 边沿突破：末K的close>基准K的High，末K的前一根K <= 基准K的High 

[选股策略]:
1. 3M1路径命中 或 3M2路径命中（两条完整路径取 OR；两路径都命中时优先记 3M1）
2. 单路径内：符合该路径多头排列，且边沿突破金叉交叉K 或者 死叉交叉K 或者 多头均线关键K

[可选配置]：
	最低日均成交额：默认3000万，可调整


[补充选股条件]：
1. 父级别底部位置
2. Min60MA之上
3. 父周期符合条件：
	水下：次波段High之上、前2根K的High之上
	水上：次波段探底回升、次波段未探底前High之上收阳(且 次波段High之上)

[止盈]：次级别破坏MA均线趋势
[止损]：



## 策略2：MA均线多头突破MA策略（3M = 3M1 ∨ 3M2），超短/短/中/长线（30分钟、日线、周线、月线）
[名词定义]:
-- MA5：本档周期下，5日均线。如周期为月，即5根月K的均线 
-- MA10：本档周期下，10日均线。如周期为月，即10根月K的均线 
-- MA20：本档周期下，20日均线。如周期为月，即20根月K的均线 
-- MA30：本档周期下，30日均线。如周期为月，即30根月K的均线 
-- 均线MAX: max(MA5, MA10, MA20, MA30)
-- 3M1多头排列：MA5 >= MA20 且 MA10 >= MA20
-- 3M2多头排列：MA5 >= MA30 且 MA10 >= MA30
-- 3M均线多头排列: 3M1路径命中 或 3M2路径命中
-- 边沿突破均线MAX：末K的close > 均线MAX，末K的前一根K的close <= 均线MAX
-- 开盘突破均线MAX：末K的close > 均线MAX，末K的open <= 均线MAX

[选股策略]:
1. 3M1路径命中 或 3M2路径命中（两条完整路径取 OR；两路径都命中时优先记 3M1）
2. 单路径内：符合该路径多头排列，且边沿突破均线MAX 或 开盘突破均线MAX

[可选配置]：
	最低日均成交额：默认3000万，可调整
	30分钟周期均线突破：30分钟满足3M均线多头排列，且 边沿突破均线MAX 或 开盘突破均线MAX
	大周期均线多头排列：日线3M均线多头排列、周线3M均线多头排列、月线3M均线多头排列，默认不开启，多选时取交集

[补充选股条件]：
1. 父级别底部位置
2. Min60MA之上
3. 父周期符合条件：
	水下：次波段High之上、前2根K的High之上
	水上：次波段探底回升、次波段未探底前High之上收阳(且 次波段High之上)

[止盈]：次级别破坏MA均线趋势
[止损]：跌破成本5%
